要求：
1. 照【作者想要什么】写；作者没说的，按定调和已有的设定，补这本书眼下最缺、最用得上的。
2. 每一条按【这一类的栏目】一栏一栏写在 values 里，栏目名照抄。这是给作者挑的候选，写清要点就够，作者挑中了想要细的，会再让你写细：
   - 名字下面的短栏目只写几个字：别名只写别的叫法，几个叫法用顿号隔开，不加解释；年龄写数字，或「十八九」这样；所属写哪个宗门、家族、势力。
   - 正文栏目每栏一两句，最多三句，能列的一条条列。只有一栏「内容」的，写一小段，150 字以内。
   - 拿不准的栏目宁可空着，不要硬编。
3. 不要和【设定库目录】里已有的重复，换个名字也算重复。名字好记、不拗口，和已有的人名、地名不撞车。
4. 和定调、底牌、已有的设定对得上：境界、地名、人名用设定库里的叫法；提到已有的人和地方，照目录里的名字写。底牌不要直接写出来，只能露一角。
5. 几条之间要有实质差别，让作者有得挑。这类书读者要的爽点写到位，再加一两处新意；能打、有代价、有反差、想得出画面。
6. 角色的「定位」只写这七个词里的一个，不加别的字：主角、女主、男主、班底、对手、导师、配角。和主角作对的写对手。
7. 一级一级往上排的类别（比如等级体系）：values 只写一栏「总说明」（怎么往上升、越级多难、有什么代价），各级写在 levels 里，从低到高，高阶的介绍可以先空着。
8. note 只写一两句：这几条各自是什么思路。
