# 后宫玄幻爽文

## 总则
- 读者要的是「憋屈—爆发」的情绪落差：先让主角和读者一起被看轻、被逼到墙角，再让主角用读者没想到、回头一看又合情合理的方式翻盘。压抑可以短，爆发必须足。
- 主角主动：每一段都是主角想要什么、去争什么，而不是麻烦找上门再被动应付。
- 爽点分层：打脸（情绪）、升级（实力）、收获（宝物、地位、势力）、感情（女主心动或关系推进）、揭秘（身世、世界真相），一个单元至少占两种。
- 世界越走越大：地图、对手、女主的层次一卷比一卷高；回到旧地图时，用旧人旧事的反差制造爽感（当年看不起他的人如今只能仰望）。
- 女主不是奖品：每位女主有自己的目标、立场和底线，会拒绝、会误会、会反过来帮主角破局；后宫靠一个个立得住的人物撑起来，而不是靠数量。只有一位女主时，把「女主」「修罗场」相关的打法换成这位女主的感情推进。

## 线索
- 女主登场节奏：第一卷最多两位女主正式登场（一位主线女主，另一位可以只是惊鸿一瞥）；之后大约每卷一位新女主，登场的卷错开；前一位的感情线走到「确认关系」或「稳定」之后，再让下一位进场。
- 每位女主的感情线五步：初遇（带反差或冲突，不要一见钟情）→ 误会或立场对立 → 靠近（共同经历、看到对方另一面）→ 确认关系 → 高光或考验（为对方付出代价、修罗场里的选择）。
- 确认关系的方式各不相同，可以选：并肩死战后的坦白、立场冲突中主角选择了她、她主动争取（反向追求）、长辈或宗门阻挠下的抗命、旧约兑现（婚约、承诺）、她看穿主角的伪装后依然站在他这边、主角为她报仇雪恨。救命之恩、双修疗伤全书各最多用一次。
- 修罗场是一条单独的情绪线：女主之间要有各自的关系（敌对、师徒、姐妹、竞争）；每隔一两卷出现一次，形式换着来（同席、争夺、误会、联手对外）。
- 反派阶梯：每卷一个主对手，外加贯穿两三卷的幕后黑手；对手的层次和主角当时的实力上限相匹配，不要让随手可灭的反派霸占整卷；最终大反派在前期就以传说、阴影或代理人的方式出现过。
- 金手指成长：前期每卷解锁一个新能力或新用法；中期放缓，改为旧能力的新组合；后期金手指的来历本身成为谜团线的一部分。
- 谜团线分三层：主角身世、金手指来历、世界真相，逐层揭开，每揭开一层都改变主角的目标。

## 分卷
- 卷是「换地图」的单位：每卷一个新舞台（家族小城 → 宗门 → 大域 → 上界……），新舞台带来新规则、新对手和新女主。
- 每卷安排一个「大场面」作为卷末高潮：宗门大比、秘境夺宝、拍卖会风波、势力存亡之战、上界选拔……同一种大场面全书最多两次，第二次必须换玩法。
- 欲扬先抑落到卷：每卷开头主角在新地图都是外来者、低位者，先抑；卷中段打响名声；卷末一战定位。连续两卷的「抑」不要是同一种（被退婚、被欺压、被追杀、被误解、实力被封印……换着来）。
- 每卷至少推进一条感情线、一条反派线和一次谜团揭示；每两三卷安排一次全书级的大反转。
- 实力区间：前三卷升级快（大约每卷跨一个大境界），中期放缓，后期以领悟、法则、身份为主，避免数值膨胀。

## 单元
- 一个单元一个核心套路，最多再叠一个小套路；连续两个单元不用同一个核心套路。
- 欲扬先抑是每个单元的骨架：起（目标与压力）→ 抑（被轻视、被设局、失去什么）→ 扬（主角布局、底牌一点点露出来，读者看得到他在准备）→ 爆（当众翻盘，之前每一笔压抑都得到回报）→ 余波（各方反应、收获、新钩子）。抑最多占单元的三分之一；抑的来源换着来（权势、规则、误会、女主的立场、金手指的副作用）。
- 一卷之内单元强度呈阶梯：小高潮一个接一个，最后一两个单元是全卷最大的高潮；卷首单元要快，三章内进入冲突。
- 每个单元至少把一条感情线或修罗场往前推一步，不要让女主整个单元只出现在对话里。
- 反派要先赢一次：每个对手至少让主角吃一次亏、丢一样东西或付出代价，主角的翻盘才有分量。

## 章节
- 单元第一章就抛出目标或压力；高潮放在倒数一两章。
- 打脸三拍：对方的轻视要具体（当众、有台词、有赌注）→ 主角的反击要有过程（不是一招秒杀了事）→ 余波落到利益上（赌注兑现、地位改变、女主态度变化）。旁观者的反应要写，但每次换人、换方式。
- 女主出场的章节要有一个只属于她的画面（动作、台词或细节），让读者记住她，而不是只写美貌。
- 扮猪吃虎的章节：伪装要有合理理由；揭穿前给读者两三处暗示，读者先知道、配角后知道。
- 每章结尾留钩子：新敌人现身、底牌被看穿、女主误会、宝物异动、身份将被揭穿……同一种钩子不要连用三章。

## 套路库
### 退婚打脸（全书最多 1 次）
- 用在：开篇或第一卷前段，把主角的处境和动机一次立起来。
- 节拍：当众退婚（对方有合理的理由和靠山）→ 主角立约（几年之约、比试之约）→ 中间用一两次小交锋提醒这个约定 → 兑现时对方已经无法回头。
- 出新：退婚的一方不是坏人、另有苦衷；被退婚的是女主一方；兑现时主角选择放下，而不是羞辱对方。

### 扮猪吃虎（全书最多 6 次）
- 用在：主角进入新地图、实力或身份被低估时。
- 节拍：伪装的理由 → 被人轻视并立下赌注 → 两三处暗示让读者先知道 → 关键时刻亮出真实实力 → 旁观者反应 → 伪装暴露带来更大的麻烦。
- 出新：伪装的不是实力，而是身份、阵营或金手指；被看穿的反而是主角；让某位女主成为唯一的知情者。

### 拍卖会（全书最多 3 次）
- 用在：需要宝物、需要多方势力同场、需要主角以财力或眼力压人时。
- 节拍：主角带着目标进场 → 竞价中与对手结怨 → 主角靠眼力（识破赝品、看出隐藏价值）或财力压过对手 → 场外截杀 → 反杀并揭开宝物的秘密。
- 出新：主角是卖家而不是买家；拍卖的是人或情报；截杀者另有其人；宝物背后连着一条长线伏笔。

### 秘境探险（全书最多 4 次）
- 用在：需要集中升级、获取传承，或者让多个势力和女主在封闭环境里碰撞时。
- 节拍：开启前的名额之争 → 进入后的规则与危险 → 多方争夺 → 主角拿到核心机缘（要付出代价或通过考验）→ 出秘境时被围堵。
- 出新：秘境本身是一个谜（为何存在、谁留下的）；秘境规则和主角的金手指相克；机缘不是功法，而是一段记忆、一个人。

### 宗门大比（全书最多 3 次）
- 用在：卷末高潮或中段扬名，主角要在规则之内当众战胜天才时（各种天才对决、选拔赛都算这一类）。
- 节拍：报名受阻 → 预选被针对 → 一路过关，每一轮对手的打法不同 → 决赛对上本卷主对手 → 赛后奖励与新身份。
- 出新：比的不只是战斗（炼丹、阵法、推演、赌约）；主角故意输掉一场换更大的东西；裁判或规则本身就是对手的一部分。

### 修罗场（全书最多 5 次）
- 用在：两位以上女主已经登场，感情线需要推进或制造张力时。
- 节拍：两位女主因主角相遇 → 各自的立场和误会 → 主角的态度与选择 → 收场时关系发生变化（敌意减弱、结成同盟或更加激化）。
- 出新：女主之间原本就有关系；修罗场和外部危机同时爆发，逼主角在生死关头做选择；以女主联手对付外敌收场。

### 女主登场（每位女主 1 次）
- 用在：新女主进场的单元。
- 节拍：登场时与主角处于对立或不对等的位置（高位者、敌对阵营、雇主、对手）→ 展示她的能力和底线 → 留下一个让读者好奇的秘密。
- 出新：不用「英雄救美」开局；让她先救主角、先坑主角或先赢主角一次。

### 英雄救美（全书最多 2 次）
- 用在：确实需要主角在女主面前展现担当时。
- 节拍：女主陷入危机是因为她自己的选择，而不是莫名其妙被抓 → 主角出手要付出代价 → 获救后女主的反应符合她的性格（可能是嘴硬、不领情）。
- 出新：救下的不是女主本人，而是她在乎的人或东西；救人失败了一半。

### 身份揭晓（全书最多 4 次）
- 用在：主角或关键人物的隐藏身份需要引爆剧情时。
- 节拍：前面至少埋过两处暗示 → 在最不合时宜的场合揭开 → 各方立场重新洗牌。
- 出新：揭开的是反派或女主的身份；揭晓之后主角的处境变得更糟，而不是更好。

### 绝境追杀（全书最多 4 次）
- 用在：主角得罪了远超自己的势力，需要逃亡、转移舞台或磨炼时。
- 节拍：追杀开始（实力差距明确）→ 一次次险死还生，每次靠不同的办法 → 途中结识新的人或得到新的东西 → 反杀追兵或甩掉追杀，换到新地图。
- 出新：追杀者有自己的苦衷或底线；逃亡途中主角反过来给追杀者设局。

### 势力存亡战（全书最多 4 次）
- 用在：卷末大场面，主角所在的家族、宗门或城池面临灭顶之灾时。
- 节拍：危机压境，盟友动摇 → 内奸或叛徒暴露 → 主角挑起大梁，安排多线作战 → 最惨烈的时刻，主角的底牌或布局生效 → 战后格局改变。
- 出新：主角救下的势力并不值得救；赢了一战却输了人心；敌人的进攻本身是更大阴谋的一部分。

## 破局手法
单元高潮时主角靠什么赢，归入下面一类（卷纲里每个单元标明一类）：
- 算计设局（不限次数，但不能连续三个单元）：提前布局、借刀杀人、将计就计。
- 底牌显露（不限次数，但不能连续两个单元）：金手指、隐藏的功法或宝物。
- 借势借力（不限次数，但不能连续两个单元）：利用势力矛盾、规则、舆论。
- 越级硬拼（每卷最多 2 次）：靠战斗意志和代价硬打赢，赢了要付出明确的代价。
- 临阵突破（全书最多 4 次）：生死关头突破境界。
- 长辈出手（全书最多 2 次）：师父、家族长辈、神秘强者出手。
- 女主相救（全书最多 2 次）：女主出手扭转局面。
- 双修解困（全书最多 1 次）：靠双修疗伤、解毒或突破。
- 身份压人（全书最多 3 次）：亮出背景或身份让对手退缩。

## 防重复
- 同一种破局手法不能连续两个单元使用（算计设局可以连续两个，不能连续三个）；标了上限的手法，全书用够就不能再用。
- 套路库里标了上限的套路，全书用够就不能再用；连续两个单元不用同一个核心套路。
- 感情线确认关系的方式各不相同：救命之恩、双修疗伤全书各最多一次；不要每位女主都在主角落难时出现。
- 反派不能靠降智输：不能在占优时停下来说话、不能明知主角有底牌还托大单挑、不能前后智商不一致；输了要有后手或者付出代价。
- 打脸后的旁观者反应不能千篇一律：倒吸凉气、目瞪口呆、跪地求饶这类描写，同一种一个单元最多一次。
- 宝物和机缘不能总是「恰好」落到主角手里：至少一半的收获要靠主角主动争取或付出代价。
- 「被看不起 → 打脸」的结构一卷之内最多三次，其余单元换成别的情绪（悬疑、温情、危机、背叛）。
