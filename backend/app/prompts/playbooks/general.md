# 通用

## 总则
- 每一段剧情都回答三个问题：主角想要什么、谁在阻止他、他付出了什么代价。
- 情绪要有落差：先压后扬、先甜后虐、先疑后解；平铺直叙的段落要短。
- 主角主动推动剧情；配角和对手有自己的目标，会在主角看不到的地方行动。
- 世界和冲突逐步升级：新舞台、新规则、新对手；旧人旧事在后面以新的面貌回来。

## 线索
- 主线之外至少配一条情感线（爱情、友情、亲情、师徒都可以）、一条对手线、一条谜团线，轮流推进。
- 情感线的每一步关系变化都要有具体事件推动，每一步换一种方式；不要每次都靠「危难相救」拉近关系。
- 对手线形成阶梯：每个阶段的对手各有目标和手段，一个比一个难缠；最终对手在前期就以某种方式露过面。
- 谜团线分层揭开：每次揭开一部分，同时抛出新的疑问；最大的真相留到后期。

## 分卷
- 每卷有独立的舞台、目标和高潮；卷末的结果改变主角的处境，并引出下一卷的问题。
- 每卷开头先让主角处于不利位置（先抑），中段积累，卷末爆发。
- 各卷的卷末高潮类型要错开：对决、揭秘、抉择、逃亡、营救、谈判、背叛……同一种卷末高潮全书最多两次。

## 单元
- 一个单元一个核心套路，连续两个单元不用同一个核心套路。
- 欲扬先抑是单元的骨架：起（目标与压力）→ 抑（受挫、失去、被误解）→ 扬（准备与反击）→ 爆（高潮）→ 余波（后果与新钩子）。抑最多占单元的三分之一。
- 一卷之内强度呈阶梯，最大的高潮放在最后一两个单元；卷首单元要快。
- 对手至少先赢一次，主角的胜利才有分量。

## 章节
- 每章有一个推动剧情的事件和一个情绪高点，不要只有过渡。
- 高潮章写足过程和周围人的反应；反应的人和方式要换着写。
- 揭秘之前，给读者两三处可以回头印证的线索。
- 每章结尾留钩子，同一种钩子不要连用三章。

## 套路库
### 以弱胜强（全书最多 8 次）
- 用在：主角面对明显更强的对手时。
- 节拍：实力差距摆在明面上 → 主角找出对方的弱点或规则漏洞 → 付出明确的代价 → 赢下来，代价延续到后面。
- 出新：赢在算计和环境，而不是硬拼；赢了却失去重要的东西。

### 比试竞赛（全书最多 4 次）
- 用在：需要主角在规则之内当众证明自己时。
- 节拍：报名受阻 → 前几轮被针对 → 每一轮换一种打法 → 决赛对上主对手 → 赛后的奖励与新身份。
- 出新：比的不是武力，而是智力、技艺或人心；主角故意输掉一场换更大的东西。

### 寻宝探险（全书最多 4 次）
- 用在：需要获取关键物品、进入未知地点时。
- 节拍：得到线索 → 进入后的规则与危险 → 多方争夺 → 拿到宝物（付出代价或通过考验）→ 出来时被围堵。
- 出新：宝物本身是个谜；真正的收获不是宝物，而是一段真相。

### 潜入调查（全书最多 5 次）
- 用在：主角需要拿到证据、情报时。
- 节拍：目标与难度 → 伪装或布置 → 意外打乱计划 → 临场应变 → 拿到东西，却发现事情比想象的更大。
- 出新：主角查的是自己人；被调查的一方早有准备，反过来利用主角。

### 对质揭穿（全书最多 4 次）
- 用在：真相大白、当众扳倒对手时。
- 节拍：对手占尽优势、颠倒黑白 → 主角一步步摆出证据 → 对手垂死挣扎的反扑 → 最后一击 → 众人的反应和后果。
- 出新：揭穿之后发现对手也是棋子；主角为了揭穿付出了代价。

### 营救（全书最多 3 次）
- 用在：重要的人落入敌手时。
- 节拍：人被抓（因为他自己的选择）→ 主角权衡与准备 → 行动中出现变数 → 救出来，但有人留下或受伤。
- 出新：被救的人不想被救；营救本身是对手设的局。

### 背叛（全书最多 3 次）
- 用在：需要剧情大转折、让主角失去依靠时。
- 节拍：前面写足信任和这个人的可爱之处 → 埋下两三处可以回头印证的暗示 → 背叛发生在最痛的时刻 → 动机合情合理。
- 出新：背叛者是为了保护主角；主角早就知道，将计就计。

### 身份揭晓（全书最多 4 次）
- 用在：隐藏的身份需要引爆剧情时。
- 节拍：前面至少埋过两处暗示 → 在最不合时宜的场合揭开 → 各方立场重新洗牌。
- 出新：揭晓之后主角的处境变得更糟，而不是更好。

### 绝境逃亡（全书最多 3 次）
- 用在：主角面对无法正面抗衡的力量时。
- 节拍：危机降临 → 一次次险死还生，每次换一种办法 → 途中的新相遇或新发现 → 逃出生天或反杀追兵，局面改变。
- 出新：追捕者有自己的苦衷；主角在逃亡中反过来设局。

## 破局手法
单元高潮时主角靠什么赢，归入下面一类（卷纲里每个单元标明一类）：
- 算计设局（不限次数，但不能连续三个单元）：提前布局、将计就计。
- 底牌显露（不限次数，但不能连续两个单元）：之前埋下的能力、物品或人脉派上用场。
- 借势借力（不限次数，但不能连续两个单元）：利用矛盾、规则、舆论。
- 硬拼取胜（每卷最多 2 次）：靠意志和代价硬打赢。
- 临阵突破（全书最多 4 次）：关键时刻能力突然提升。
- 外援相助（全书最多 3 次）：别人出手扭转局面。
- 运气巧合（全书最多 1 次）：意外的好运。

## 防重复
- 同一种破局手法不能连续两个单元使用（算计设局可以连续两个，不能连续三个）；标了上限的手法，全书用够就不能再用。
- 套路库里标了上限的套路，全书用够就不能再用；连续两个单元不用同一个核心套路。
- 关系的推进方式各不相同：「危难相救」全书最多两次。
- 对手不能靠降智输：不能在占优时停下来说话、不能前后智商不一致；输了要有后手或者付出代价。
- 主角的收获至少一半要靠主动争取或付出代价，而不是恰好落到手里。
