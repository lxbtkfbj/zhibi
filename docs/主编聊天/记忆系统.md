# 编辑部的记忆（设计稿）

编辑部会记住关于作者和这本书的事：作者说「记住」它就记，它觉得重要也会自己记。记了会在回答下面告诉作者，点进去能看、能改、能删。原来的「写作要求」并进来，成为记忆的一种。

> 第二版（10-22）对照代码补了这些：开书和拍板时会自动记（第 6 节）；回到存档、聊天里「修改」、删书时记忆怎么办（第 7 节）；编辑部正在写、在等拍板时照样能记；三种提示都能「撤销」；全局的只能一直有效、和这本书打架时听这本书的；两种记忆怎么分（克苏鲁那条改成写书时照做）；拆的书、私聊里说「记住」怎么办；程序回给模型的几句话（9.4、9.7）。
>
> 第三版（10-23）作者看过：回到存档时记忆不动、三种提示都能撤销、「别写克苏鲁」放进写书时照做，都同意。作者指出：看这一章时说「打斗多一点」，不该变成以后每章都拼命多写打斗。所以看稿时写的意见不再自动当成规矩，改成交给主编判断（第 6 节，新提示词见 9.9）。

## 1. 记忆长什么样

**两种**

| 种类 | 是什么 | 什么时候用 |
|---|---|---|
| 写书时照做 | 编辑部写书时要守住的：写什么、不写什么、怎么写（节奏、文风、尺度、写法，也包括否掉的内容方向）。原来的写作要求就是这一种 | 排大纲、写正文、审稿时每次都带，必须落实；聊天时也看得到 |
| 聊天时记得 | 关于作者这个人的：口味、作者的话该怎么理解、怎么跟作者合作更顺；还有商量好了、但暂时写不进书里的事 | 只在聊天时用，写书时看不到 |

分不清时这样想：编辑部自己埋头写书、没人在旁边提醒时也得守住的，是「写书时照做」；只在跟作者商量时用得上的，是「聊天时记得」。

**两个库**

- 全局：所有书都用，比如口味、忌讳、合作习惯。
- 这本书：只在这本书用。

在哪本书里，编辑部就用「全局＋这本书」；别的书的记忆看不到。

- 全局的「写书时照做」只能一直有效。只管下一章、这一卷、下一卷，说的是这本书的章和卷，只能放这本书。
- 全局和这本书说的打架时，听这本书的。

**每条记忆**

- 编号：比如「记12」，编辑部改、删的时候用。所有记忆统一编号，不分全局和哪本书，一个编号只指一条。
- 简述：一句话，让人一眼看懂记的是什么。它会放进编辑部每次都看的目录里，所以要短、要准。
- 详细内容：作者原话怎么说的、为什么；「写书时照做」的写清楚具体要怎么做。
- 「写书时照做」的还有「管多久」：一直有效、只管下一章、只管这一卷、只管下一卷（沿用原来写作要求的规矩）。
- 哪天记的、从哪来（聊天里记的／你加的／方案卡／开书时答的／看稿时说的），由程序记，不用模型写。
- 过期的（比如只管第 3 章，第 3 章已经定稿）：聊天和写书都不再带，记忆管理里还留着，标「已过期」。

**例子**

| 作者说的 | 记成 |
|---|---|
| 记住，以后每章结尾都留个钩子 | 这本书 · 写书时照做 · 一直有效：每章结尾留钩子 |
| 下一章节奏快一点 | 这本书 · 写书时照做 · 只管下一章：下一章节奏加快 |
| 我所有书都不写床戏 | 全局 · 写书时照做 · 一直有效：不写床戏，感情戏点到为止 |
| 退一步吧，不要写这种精神污染克苏鲁式的设定了 | 这本书 · 写书时照做 · 一直有效：不写克苏鲁那种精神污染的设定 |
| 我喜欢传统爽文，像逆天邪神那种 | 全局 · 聊天时记得：喜欢传统爽文，例子要像逆天邪神 |
| 我说喜欢这几个题材，不代表要全部融合 | 全局 · 聊天时记得：说喜欢几种题材，不等于要融合在一起 |
| 别一次给我那么多选项，挑两个最好的说 | 全局 · 聊天时记得：给选项时只挑两个最好的 |
| 女主的身世先别定，写到第二卷再说 | 这本书 · 聊天时记得：女主身世先不定，写到第二卷再商量 |

克苏鲁那条第一版放在「聊天时记得」，改了：新建设定、补齐设定是编辑部另外动笔写的，那时只带「写书时照做」。放在「聊天时记得」，写设定时就看不到，又会写出克苏鲁来。

## 2. 编辑部怎么用记忆

- **聊天**（群聊、私聊，四个角色都一样）：提示词里放记忆目录，全局和这本书、两种都列，每条一行：编号、管多久（只有写书时照做才有）、简述。能调工具的模型要细节就自己翻；不能调工具的只看简述。
  - 这样点了「新对话」也记得作者的喜好、否掉过的方向，不用作者再说一遍。
- **写书**：现在所有带「作者的要求」的地方（开书、排大纲、拆卷、出章纲、写正文、审稿……），换成带「写书时照做」的记忆（全局＋这本书，按管多久筛，过期的不带），和原来一样必须落实。
  - 每条用详细内容，换行并成一行；只管某章某卷的，前面照旧带「（只管第 N 章）」。
  - 全局的排前面，这本书的排后面，各自按记的先后。那一块的标题照旧是「作者的要求（必须落实；后面的要求与前面冲突时以后面的为准）」，所以打架时听这本书的。
  - 26 份写书的提示词都不用改。
- **编辑部正在写的时候**：新记、改、删的「写书时照做」，从下一步起照办，不进待处理（和现在的写作要求一样）。

## 3. 编辑部什么时候记

- 作者明说「记住……」「以后都……」「别再……」；
- 作者表明喜好或忌讳；
- 作者否掉一个方向，并说了理由；
- 商量定了一件事：能写进书的（设定、大纲、简介），先问作者要不要写进去，因为只记在记忆里，编辑部自己排大纲、写正文时看不到；暂时写不进去的（比如大纲还没排到），才记下来。

不记：

- 一次性的闲聊；
- 已经写进设定、大纲、简介的；
- 编辑部自己的想法和建议，只记作者的意思。

另外：

- 同一件事已经记过，就改那一条，不重复记；作者改了主意，也是改那一条。
- 作者说「这条不用记了」「记错了」：删掉。
- 作者说「先别改」「先别动」「我再想想」：照原来的规矩，一处都不动，写书时照做的也不记。

**谁能记**

- 群聊里能调工具的模型：两种都能记、能改、能删。作者现在的两个 gemini 都是这条路。编辑部正在写、在等你拍板时也照样能记：记忆不是书，不用等。
- 不能调工具的群聊（先分流那条路）：分流认出「以后要照做的事」时，照旧自动记，只是记成「这本书 · 写书时照做」。这条路只能记这一种，「记住我喜欢……」「我所有书都……」这种，记不成全局，也记不成聊天时记得。
- 私聊：只看记忆，不记。作者在私聊里说「记住……」，编辑部请作者到群聊里说。
- 拆的书的聊天：不接记忆，看不到也不记。
- 开书时的回答和选择：程序照旧自动记（见第 6 节）。
- 看稿时写的意见：交给主编判断，有以后要一直照做的才记（见第 6 节、9.9）。

## 4. 作者看到什么

**编辑部的回答下面**（和「查了：……」同样的小字，一条一行，每行后面都有「撤销」）：

| 编辑部做了 | 这一行 | 点「撤销」 | 撤销以后这一行 |
|---|---|---|---|
| 新记一条 | 「记住了：{简述}」，后面淡字「{种类} · {全局／这本书}」，写书时照做的再加「 · {管多久}」 | 删掉这条 | 「没记：{简述}」 |
| 改了一条 | 「改了一条记忆：{改后的简述}」 | 换回改之前的样子 | 「换回了原来的：{原来的简述}」 |
| 删了一条 | 「忘掉了：{简述}」 | 找回来，编号不变 | 「找回来了：{简述}」 |

- 编辑部正在写的时候记的「写书时照做」，淡字后面再加「 · 正在写的从下一步起照办」。
- 这条后来又被改过，「撤销」变灰，悬停提示「这条后来又改过，去「记忆」里改」；后来删掉了，悬停提示「这条后来删掉了」。
- 点「记住了」「改了一条记忆」那一行的字，打开记忆管理、跳到那一条；「忘掉了」那行点了不跳。
- 原来那一行的「改一下」不要了：要改，点这一行进记忆里改。

**分流那条路记的**（原来「加了一条写作要求：……」那一行，在作者那句话下面）：和上面「记住了」那一行一模一样，也有「撤销」。

**方案卡**：「写作要求」那一类，卡上显示成「记忆 · 写书时照做 · {管多久}」；点「按这个来」时记成这本书的「写书时照做」，结果那一行也是「记住了：……」加「撤销」。

**开书时的回答和选择**：照旧自动记，不出「记住了」那一行。

**看稿时写的意见**：主编判断完，在聊天里回作者一句（9.9 的 reply）；记了的，下面出「记住了：……」那一行，带「撤销」，和上面一样。另外改两句现有的字：
- 试读时写了意见，页面上回的那句「记下了：以后每一章都照这个写（记在写作要求里，随时能改）」，改成「好，交给主编：要后面每章照着写的，会记进记忆」。
- 试读完主编在聊天里说的「意见记下了，后面每一章都按这个来写。」去掉，换成 9.9 的 reply。

## 5. 记忆管理

- **位置**：编辑部窗口顶上「待处理」旁边，叫「记忆」。和待处理一样，点了整个窗口换成记忆那一页，「回到聊天」换回来。拆的书的编辑部窗口没有这个按钮。
- **两页**：「这本书」「全局」。每页分两组：「写书时照做」「聊天时记得」。
- **每条**：
  - 简述一行；
  - 下面淡字：管多久（只有写书时照做才有）· 哪天记的 · 从哪来（聊天里记的／你加的／方案卡／开书时答的／看稿时说的）；
  - 点开看详细内容。
- **过期的**：排在「写书时照做」那组最后，变淡，淡字开头是「已过期 · 」，能删。
- **能做的**：
  - 「改」：简述、详细内容、种类、全局还是这本书、管多久，都能改。改成全局时，管多久只能一直有效。
  - 「删」：删了出「删掉了：{简述}」和「撤销」。
  - 顶上「加一条」：作者自己写。简述必填；详细内容可以不填，不填就和简述一样；种类默认「写书时照做」，放哪个库默认是正在看的那一页，管多久默认一直有效。
  - 「整理一下」：只在「这本书」那页的「写书时照做」，到 5 条才出，沿用原来写作要求的整理（合并重复的、去掉打架的、改清楚说不清的，作者勾了才改）。全局那页不出。
- 编辑部在聊天里记、改、删的，开着的记忆一栏跟着变。
- **空的时候**：「还没有记忆。在聊天里说「记住……」，编辑部就会记下来。」
- **本书设置**：「写作要求」那一节去掉，换成一行「写书时照做的规矩，现在放在编辑部的「记忆」里。」，后面「去看看」。书页上「本书设置」按钮的悬停提示「这本书怎么写：人称、每章字数、写作要求……」去掉「写作要求」。

## 6. 原来的写作要求

- 全部搬成这本书的「写书时照做」：简述和详细内容都用原文（原文超过 40 字的，简述取前 40 字加「……」），管多久、来源照旧。作者现在所有书都是 0 条。
- 现在往写作要求里加东西的地方，改成下面这样。记的都是这本书的「写书时照做」：

| 入口 | 怎么记 | 简述 | 详细内容 | 从哪来 |
|---|---|---|---|---|
| 群聊分流认出的 | 照旧自动记 | 分流整理好的那句要求 | 作者原话 | 聊天里记的 |
| 方案卡里的 | 照旧，点「按这个来」时记 | 卡上那一条 | 卡上那一条 | 方案卡 |
| 主编自己动手的：原来用 make_changes 的「写作要求」那一类，改成用 remember | 模型自己判断 | 模型写 | 模型写 | 聊天里记的 |
| 开书时的回答和选择：回答「动笔前提问」；挑故事方向时选了哪个、写多少万字、书名 | 照旧自动记：这些本来就是定整本书的 | 原话（超过 40 字取前 40 字加「……」） | 原话 | 开书时答的 |
| 看稿时写的意见：编辑部停下来请作者看稿时（开书的各步、试读、篇、卷纲、章纲），作者在框里写的话；让改的、点确认时顺手写的都算 | **不再自动记**，交给主编判断，见下面 | 主编写 | 主编写 | 看稿时说的 |
| 看稿时点的「改成……」 | 不记：只用来改眼前这一处 | — | — | — |
| 新建书时，新书默认里的「其他规矩」 | 照旧自动记 | 原话（同上） | 原话 | 你加的 |

**看稿时写的意见**：以前一律存成一直有效的规矩。作者指出这不对：看这一章时说「打斗多一点」，后面每一章都会拼命多写打斗。改成：
- 意见照旧拿去改眼前这一处（这一篇、这一卷的卷纲、这几章的章纲、开书的这一步）。改的时候直接用意见原话，不靠记忆。
- 另外交给主编判断（新提示词，见 9.9）：意见里有作者要以后一直照做的，才记成这本书的「写书时照做」；只说眼前这一处的，不记。
  - 「这一篇女主别出场」：只改这一篇，不记。
  - 「这章打斗多一点」：只改眼前这一处，不记。
  - 「打斗太少了，以后每章都多写点」：改眼前这一处，并记住「每章打斗多写一些」。
  - 试读时说「对话太多，叙述太少」：前 3 章不会重写，这句是说给后面的章听的，记住「少写对话，多些叙述」。试读时说「第二章反派太蠢」：只说那一章，不记，主编回话告诉作者去「正文」那一页让编辑部重写第二章。
- 判断在后台做，不耽误编辑部照意见改。用主编的模型。
- 判断失败时，主编在聊天里说：「这段意见没来得及判断要不要记（{原因}）。要以后都照做，在聊天里跟我说「记住……」。」
- 原来的写作要求表和接口，搬完不再用（由执行方决定删掉还是留着不用）。

## 7. 记忆不跟着书进退

- **回到存档**：记忆不动。存档里不再存记忆，「和现在比」里不再有「写作要求」那一组；以前的存档里带着的写作要求和「其他规矩」，回到那一档时都不管。
  - 为什么：记忆记的是作者的意思。书退回去，作者的意思没变；哪条不要了，去记忆里删。
- **聊天里「修改」**（这句和后面的聊天收起来）：记忆不退。那句提醒「这句和后面的话改过书（n 处）」，数的时候不算记忆。
- **删一本书**：这本书的记忆跟着删；全局的不动。

## 8. 这次不做

- 拆的书的聊天不接记忆。
- 记忆不能搜索，多了再加。
- 「聊天时记得」不会自动过期，作者自己删。
- 「聊天时记得」不进写书的提示词。所以商量定了的事，主编要先提出写进书里（第 3 节）。

### 9.4 三个工具（程序里，模型看得到）

**remember**：「记住一件事，存进编辑部的记忆；带上编号就是改那一条。」

| 参数 | 说明 |
|---|---|
| id | 要改哪一条，填目录里的编号（比如「记12」）；新记一条留空 |
| kind | 「写书时照做」或「聊天时记得」：编辑部自己写书时也得守住的（写什么、不写什么、怎么写）选「写书时照做」；只在和作者商量时用得上的（作者的口味、作者的话该怎么理解、怎么跟作者合作、暂时写不进书的事）选「聊天时记得」 |
| scope | 「这本书」或「全局」：只关于这本书的选「这本书」；换一本书也成立的选「全局」；只管下一章、这一卷、下一卷的只能选「这本书」 |
| summary | 简述：一句话，让人一眼看懂记的是什么，30 字以内 |
| detail | 详细内容：作者原话怎么说的、为什么；写书时照做的，再写清楚具体怎么做 |
| lasts | 写书时照做才填：作者说了只管下一章、这一卷、下一卷的照选，没说的选「一直有效」 |

**read_memory**：「翻记忆的详细内容。目录里每条只有简述，要细节时按编号翻，一次最多 5 条。」参数 ids：要翻的编号，比如「记12」。

**forget**：「删掉一条记忆。只在作者明说这条不要了、记错了的时候用。」参数 id：要删的编号。

**回给模型的话**（做成了的都以「做成了：」开头，好让 9.1 说的第 7 条管得住）：

| 情况 | 回的话 |
|---|---|

| 改了一条 | 「做成了：记12 改成了「{简述}」。」 |

| 同一个库、同一种里，已经有简述一字不差的 | 「做成了：目录里已经有这一条（记12），没有重记。」 |
| 删了一条 | 「做成了：删掉了记12「{简述}」。」 |
| 编号不在目录里（别的书的、过期的、删掉的、没有的） | 「没做成：没有这条记忆（记99），只能改、删 <记忆> 目录里有的。」 |

### 9.9 看稿时的意见要不要记（新提示词 feedback_memory.md）

主编判断用，system 照别的主编提示词，用 persona_chief。

```
作者在「{{where}}」停下来看稿，写了下面这段意见。{{what_happens}}

<作者写的意见>
{{feedback}}
</作者写的意见>

<记忆>
{{memory}}
</记忆>

你只判断一件事：这段意见里，有没有作者要编辑部以后写书时一直照做的规矩。有，就记进记忆；没有，就不记。

怎么判断：
1. 只说眼前这一处的，不记。比如「这一篇女主别出场」「这章打斗多一点」「这里节奏太慢」：眼前这一处改完就够了；记成规矩，后面每一章都会跟着跑偏。
2. 作者说了「以后」「后面」「每章」「都」，或者说的是整本书的写法、尺度、文风，才记。作者说了只管下一章、这一卷、下一卷的，照选管多久；没说的选一直有效。
3. 拿不准的不记。少记一条，作者还能再说；记错一条，后面每章都会照着错。
4. 记忆里已经有同一件事的，填上它的编号改那一条，别重记。
5. 每条写简述和详细内容：简述一句话，30 字以内，让人一眼看懂；详细内容写清作者原话怎么说的、具体要怎么做。最多 3 条。
6. reply：用主编的口吻回作者一句。记了的，说记住了什么；没记的，说清这段意见怎么处理。
```

**程序填的**：

- `where`：页面上那一步的叫法，比如「试读前 3 章」「第 3 卷的卷纲」「单元「{名称}」的章纲」「第 2 篇」「定调」「三个故事方向」。
- `memory`：和聊天里一样的记忆目录（9.3），全局和这本书都列。
- `what_happens`，按情况三选一：

| 情况 | what_happens |
|---|---|
| 作者让改（开书的各步、篇、卷纲、章纲） | 「编辑部会照这段意见改这一处，这件事不用你管。」 |
| 作者点了确认，顺手写了几句 | 「作者点了确认，这一处不再改。只说这一处的，不记，回话里告诉作者：要改这一处，在聊天里跟编辑部说。」 |
| 试读 | 「前 3 章已经写完，不会照这段意见重写，这段意见是说给后面的章听的。只说前 3 章里某一章的，不记，回话里告诉作者：要改那一章，去「正文」那一页让编辑部重写。」 |

**模型交回的**：

| 字段 | 说明 |
|---|---|
| items | 要记的，最多 3 条；没有就空着 |
| items[].id | 改记忆里已有的哪一条，填编号（比如「记12」）；新记的留空 |
| items[].summary | 简述：一句话，30 字以内 |
| items[].detail | 详细内容：作者原话怎么说的、具体要怎么做 |
| items[].lasts | 一直有效、只管下一章、只管这一卷、只管下一卷，选一个 |
| reply | 主编回作者的一句 |

- 记的都是这本书的「写书时照做」；填的编号不在目录里的，当新记一条。
- reply 以主编的身份发在聊天里；记了的，每条下面出「记住了：……」那一行（第 4 节），带「撤销」。
