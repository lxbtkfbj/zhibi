# 编辑部的记忆（设计稿，待作者看）

编辑部会记住关于作者和这本书的事：作者说「记住」它就记，它觉得重要也会自己记。记了会在回答下面告诉作者，点进去能看、能改、能删。原来的「写作要求」并进来，成为记忆的一种。

## 1. 记忆长什么样

**两种**

| 种类 | 是什么 | 什么时候用 |
|---|---|---|
| 写书时照做 | 排大纲、写正文时必须遵守的规矩：节奏、文风、尺度、写法（就是原来的写作要求） | 写书时每次都带，必须落实；聊天时也看得到 |
| 聊天时记得 | 作者的喜好和忌讳、否掉的方向和理由、商量定了但还没写进书里的事、怎么跟作者合作更顺 | 聊天时用 |

**两个库**

- 全局：所有书都用，比如口味、忌讳、合作习惯。
- 这本书：只在这本书用。

在哪本书里，编辑部就用「全局＋这本书」；别的书的记忆看不到。

**每条记忆**

- 编号：比如「记12」，编辑部改、删的时候用。
- 简述：一句话，让人一眼看懂记的是什么。它会放进编辑部每次都看的目录里，所以要短、要准。
- 详细内容：作者原话怎么说的、为什么；「写书时照做」的写清楚具体要怎么做。
- 「写书时照做」的还有「管多久」：一直有效、只管下一章、只管这一卷、只管下一卷（沿用原来写作要求的规矩）。
- 哪天记的、从哪来（聊天里记的／作者自己加的／方案卡），由程序记，不用模型写。

**例子**

| 作者说的 | 记成 |
|---|---|
| 记住，以后每章结尾都留个钩子 | 这本书 · 写书时照做 · 一直有效：每章结尾留钩子 |
| 下一章节奏快一点 | 这本书 · 写书时照做 · 只管下一章：下一章节奏加快 |
| 我所有书都不写床戏 | 全局 · 写书时照做 · 一直有效：不写床戏，感情戏点到为止 |
| 我喜欢传统爽文，像逆天邪神那种 | 全局 · 聊天时记得：喜欢传统爽文，例子要像逆天邪神 |
| 我说喜欢这几个题材，不代表要全部融合 | 全局 · 聊天时记得：说喜欢几种题材，不等于要融合在一起 |
| 退一步吧，不要写这种精神污染克苏鲁式的设定了 | 这本书 · 聊天时记得：不写克苏鲁那种精神污染的设定 |

## 2. 编辑部怎么用记忆

- **聊天**（群聊、私聊，四个角色都一样）：提示词里放记忆目录，全局和这本书、两种都列，每条一行：编号、管多久（只有写书时照做才有）、简述。能调工具的模型要细节就自己翻；不能调工具的只看简述。
  - 这样点了「新对话」也记得作者的喜好、否掉过的方向，不用作者再说一遍。
- **写书**：现在所有带「作者的要求」的地方（排大纲、拆卷、出章纲、写正文、审稿……），换成带「写书时照做」的记忆（全局＋这本书，按管多久筛），用详细内容，和原来一样必须落实。那一块在提示词里照旧叫「作者的要求」，26 份写书的提示词都不用改。

## 3. 编辑部什么时候记

- 作者明说「记住……」「以后都……」「别再……」；
- 作者表明喜好或忌讳；
- 作者否掉一个方向，并说了理由；
- 商量定了一件事，但还没写进书里（设定、大纲、简介）。

不记：

- 一次性的闲聊；
- 已经写进设定、大纲、简介的；
- 编辑部自己的想法和建议，只记作者的意思。

另外：

- 同一件事已经记过，就改那一条，不重复记；作者改了主意，也是改那一条。
- 作者说「这条不用记了」「记错了」：删掉。
- 作者说「先别改」「先别动」「我再想想」：照原来的规矩，一处都不动，写书时照做的也不记。

**谁能记**

- 群聊里能调工具的模型：两种都能记、能改、能删。作者现在的两个 gemini 都是这条路。
- 不能调工具的群聊（先分流那条路）：分流认出「以后要照做的事」时，照旧自动记，只是记成「这本书 · 写书时照做」的记忆，就是原来写作要求的那条路。
- 私聊、拆的书的聊天：只看记忆，不记。

## 4. 作者看到什么

**编辑部的回答下面**（和「查了：……」同样的小字，一条一行）：

- 「记住了：{简述}」，后面淡字「{种类} · {全局／这本书}」，写书时照做的再加「 · {管多久}」
- 「改了一条记忆：{简述}」
- 「忘掉了：{简述}」，后面「撤销」

点这一行就打开记忆管理，跳到那一条。

**分流那条路记的**（原来「加了一条写作要求：……」那一行，在作者那句话下面）：改成「记住了：{简述}」，后面淡字「写书时照做 · 这本书 · {管多久}」，再加一个「去看看」，点了打开记忆管理跳到那一条。

**方案卡**：「写作要求」那一类，卡上显示成「记忆 · 写书时照做」；点「按这个来」时记成这本书的「写书时照做」记忆。

## 5. 记忆管理

- **位置**：编辑部窗口顶上「待处理」旁边，叫「记忆」。点开是右边一栏，和待处理同一个样子。
- **两页**：「这本书」「全局」。每页分两组：「写书时照做」「聊天时记得」。
- **每条**：
  - 简述一行；
  - 下面淡字：管多久（只有写书时照做才有）· 哪天记的 · 从哪来（聊天里记的／你加的／方案卡）；
  - 点开看详细内容。
- **能做的**：
  - 「改」：简述、详细内容、种类、全局还是这本书、管多久，都能改。
  - 「删」：删了出「删掉了：{简述}」和「撤销」。
  - 顶上「加一条」：作者自己写。
  - 「写书时照做」多了，出「整理一下」（合并重复的、去掉打架的），沿用原来写作要求的整理，条数门槛也照原来。
- **空的时候**：「还没有记忆。在聊天里说「记住……」，编辑部就会记下来。」
- **本书设置**：「写作要求」那一节去掉，换成一行「写书时照做的规矩，现在放在编辑部的「记忆」里。」，后面「去看看」。

## 6. 原来的写作要求

- 全部搬成这本书的「写书时照做」记忆：简述和详细内容都用原文，管多久照旧。作者现在所有书都是 0 条。
- 加写作要求的几个入口，都改成记记忆：
  - 群聊分流认出的；
  - 方案卡里的；
  - 主编自己动手的。主编原来用 make_changes 的「写作要求」那一类，改成用新的「记住」工具。
- 原来的写作要求表和接口，搬完不再用（由执行方决定删掉还是留着不用）。

## 7. 这次不做

- 拆的书的聊天不接记忆。
- 记忆不能搜索，多了再加。
- 「聊天时记得」不会自动过期，作者自己删。

### 8.4 三个工具（程序里，模型看得到）

**remember**：「记住一件事，存进编辑部的记忆；带上编号就是改那一条。」

| 参数 | 说明 |
|---|---|
| id | 要改哪一条，填目录里的编号（比如「记12」）；新记一条留空 |
| kind | 「写书时照做」或「聊天时记得」：写书时要照做的规矩（节奏、文风、尺度、写法）选「写书时照做」，其余选「聊天时记得」 |
| scope | 「这本书」或「全局」：只关于这本书的选「这本书」；换一本书也成立的（口味、忌讳、合作习惯）选「全局」 |
| summary | 简述：一句话，让人一眼看懂记的是什么，30 字以内 |
| detail | 详细内容：作者原话怎么说的、为什么；写书时照做的，写清楚具体要怎么做 |
| lasts | 写书时照做才填：作者说了只管下一章、这一卷、下一卷的照选，没说的选「一直有效」 |

**read_memory**：「翻记忆的详细内容。目录里每条只有简述，要细节时按编号翻，一次最多 5 条。」参数 ids：要翻的编号，比如「记12」。

**forget**：「删掉一条记忆。只在作者明说这条不要了、记错了的时候用。」参数 id：要删的编号。
