# 开书

什么时候翻：怎么把一个念头变成能动笔的书：定位和卖点、主角、金手指、世界和境界、核心循环、底牌、开篇。作者还没想好写什么、正在定或者想改这些大件，或者随口问到开书的事，都先翻这本。

## 开书要做成什么

开书不是把世界想全，是让作者手里有一颗能写下去、也能卖出去的书胆。开书做完，作者应该能一句话说出这本书凭什么让人点开，写得出前三章，知道第一张地图怎么走完，知道全书大概往哪去、最大的秘密是什么。

近处要清楚，远处一句话就够。几十万字的世界开书时就想全，一定会乱，也会把作者累垮。

## 近处要想清楚的

- 定位：什么类型、给谁看、什么基调、单女主还是多女主、大概写多长。这几件读者看简介和标签时就做了决定，写到一半再改，等于换一批读者。免费平台的读者更没耐心，开头要更快，爽点要更直给。
- 卖点：读者凭什么点开，一句话说出来，能直接当简介第一句。说不成一句，多半是下面几件还没咬上。「热血成长」「逆天改命」不是卖点，谁都能说；卖点要具体到这本书独有的那一下。
- 主角：他是什么样的人（性子、行事风格、底线），开局在什么处境，眼前非做不可的是什么，长远想要什么。读者要跟着他看几百章，同一个金手指，换个性子就是另一本书。
- 金手指：能干什么，规矩和代价是什么，怎么一路变强，为什么偏偏落在他身上。它是爽的发动机，要能反复用、越用越强，又不能强到没有悬念。
- 世界和力量：这个世界的人靠什么变强、凭什么分高下。近处几层境界要清楚，读者才看得懂越级；远处先留个名字。世界最好和金手指长在一起，比如斗破的炼药师和异火，金手指就是从这套东西里长出来的。
- 第一张地图：开头几十章在哪儿发生，有哪几股势力，谁压着主角，他第一次扬眉吐气在哪，走完这张地图他往哪去。
- 核心循环：每到一张新地图，主角反复做的那件事，比如进场受压、找到破局的东西、当众爆发、拿到收获、被引向下一张地图。读者每转一圈爽一次，也看着主线往前走一步。
- 开篇：前三章发生什么，第一个钩子在哪，第一个爽点最晚第几章兑现。

## 远处一句话就行

底牌（金手指的来历、幕后的人）、终局的敌人、结局方向、后面几张地图大概往哪走。模糊不等于空白：底牌开书时就要有，哪怕只有一句，前面才好埋伏笔。

## 先后和咬合

没有死顺序，从作者最有感觉的那件开始。但你心里要有这张关系图：

- 网文多半先有「主角加金手指」这个钩子，世界围着它搭。一上来先定世界观，对新手是绕远。
- 金手指的规矩和世界的力量体系是同一套逻辑；金手指的来历落在底牌上。
- 主角的性子决定他在核心循环里怎么破局；开局的困局要逼他在前几章就用上金手指。
- 单女主还是多女主，决定核心循环里有没有「结识新的人」这一环。

每定下一件，看它牵动了哪几件；几件对不上时，先指出来，再一起调。

## 怎么判断好坏

- 新意要落在规矩上，不是换名词：把灵气改叫「源能」不算新，金手指的规矩和代价跟别人不一样才算。
- 金手指常见的毛病：没代价、没上限，主角怎么打都赢，读者就不紧张了；太复杂，三句话说不清，读者记不住。
- 主角常见的毛病：没性子，换谁来演都一样；没有自己想要的，全程被剧情推着走。
- 世界常见的毛病：开篇先铺几千字设定；地图太大，势力和人名太多，读者记不住。
- 开篇常见的毛病：慢热，前三章还在交代背景；憋屈太久，迟迟不爽；主角三章过去还没碰到金手指。
- 几种题材都想要：作者常常同时喜欢好几样，比如玄幻、恐怖规则、网游副本。能融，但要分清主菜和调料：主菜决定读者是谁、爽在哪，调料只给新鲜感。几样平分，容易两头不讨好。
- 借鉴喜欢的书：学它为什么好用，读者在哪一下爽、为什么买账；不照搬它的设定和情节。

## 怎么带一个还没想清楚的作者

- 作者说「不知道写什么」，别让他凭空回答「你想写什么」，他答不上来。从他喜欢的书往回推：哪一段看得最过瘾，最想当哪个人物，哪种爽最上头。他的口味就藏在这些回答里。
- 一次只定一件，挑现在最卡脖子的那件。上面的清单是你心里的地图，不是发给他的问卷。
- 他没主意时，给几个具体、彼此真不一样的选项，推荐一个并说清理由；他有主意时，顺着他的往下做，帮他做成，别换成你想写的书。
- 每定下一件，用一两句复述定了什么、会牵动后面哪件，让他知道离能动笔还差什么。
- 定得差不多了，提醒他把定下的落到书里（定调、设定库、大纲），别只留在聊天里。
- 书已经写了一截，作者又来问开书的事（想改金手指、想重新定主角），按同一套标准想，还要看已经写下的部分：改了以后哪些前文会对不上，读者已经在等的事会不会落空。
