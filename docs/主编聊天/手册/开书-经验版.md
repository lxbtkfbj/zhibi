# 开书

什么时候翻：作者问到怎么开一本新书，或者想定、想改一本书的世界观、主角、金手指、核心循环这些根基。

开书其实是一连串选择。一本书要先立住四块：世界观、主角驱动力、金手指、核心循环。下面每块写三样：开书时要做哪些选择，怎么取舍，新手常栽在哪。例子只为说明道理，不往作者的书上套。

从哪下手不用死守顺序，从作者最有感觉的那块开始。网文多半先有「主角加金手指」这个钩子，世界围着它搭；一上来先铺世界观，对新手是绕远。常说的套路，就是这四块合起来的样子：退婚流、废柴流说的是处境，系统流、老爷爷流说的是金手指，无限流、经营流说的是循环，灵异复苏、末世说的是世界观。

## 一、世界观

要做的选择：

- 力量或危险从哪来，按什么规矩走，用它要付什么。这是世界观的骨头，新意要落在这里；把灵气换个叫法不算新。
- 舞台多大，怎么往外打开。开局的舞台越小越好写：一座城、一个宗门、一所学校、一个副本，人少、规矩清楚，读者容易进去。更大的世界留到后面一层层打开：往外走、往上升、一个副本接一个。
- 主角站在哪一层。站得越低，往上爬的空间越大；开局就站在高处，就得另给他压力。
- 深处藏着什么。开书时一句话就够，但要有，它往往就是全书的底。
- 什么味道。压抑、热血、搞笑、温情，同一个题材能写成完全不同的书。

经验：

- 每一条设定都要问一句：它能生出冲突、撑起一圈圈故事吗？生不出来的设定，开书时不用想。
- 同题材拉开差距，靠的是几个根本的选择：危险在哪儿，主角有没有安全的地方，力量从哪来、要付什么。同样写恐怖：惊悚乐园把恐怖关在游戏剧本里；恐怖复苏让鬼闯进现实，借鬼的力量越用越接近死亡；恐怖屋让灵异藏在城市背面，主角守着一座鬼屋。三本书的味道和看点因此完全不同。
- 世界观和金手指最好是同一套逻辑：斗破的炼药师和异火，就是萧炎的金手指长出来的土壤。
- 新手常栽的坑：开书先写几万字设定，开篇先铺大段背景；世界太大，势力和人名太多，读者记不住。

## 二、主角驱动力

要做的选择：

- 他是什么样的人。先抓住一个最鲜明的特质（性子、行事风格、底线），他的选择都从这里长出来。
- 开局把他放在哪。要放在一个必须现在就动的位置：危险、屈辱、失去、被盯上。处境越具体、越急，开篇越有劲。
- 他要什么。眼前一个非做不可的小目标，带动开篇；长远一个足够大的目标，撑起全书。
- 靠什么驱动。求生、雪耻复仇、守护、找人或求真相、兴趣和欲望、改命，选一个做主，别的可以叠上去。

经验：

- 处境逼他动，人设决定他怎么动，目标决定他往哪走，三样连起来，主角才是活的。
- 读者追的是「这个人接下来会怎么做」。同一个困境，换个性子就是另一种破法；被剧情推着走的主角，换谁来都一样。
- 眼前的目标要急到不能拖：萧炎被上门退婚，当场立下三年之约，读者马上有了等着看的事。
- 动机要让读者认同，读者才愿意替他使劲。同样是想变强，为了守护、为了雪耻，读者就跟着他咬牙。
- 新手常栽的坑：主角没有自己想要的东西，只剩一句「变强」；性格只是标签（冷酷、腹黑），没落到行动上；开局太舒服，没有逼他动的东西。

## 三、金手指

金手指是主角独有的优势：别人没有，只属于他。拼命能抢到、别人也能抢到的不算；杨间的鬼怪能力都是拼死抢来的，别人也能抢，他身上最像金手指的，只有那张在关键时刻透露消息、消息还掺毒的人皮纸。

要做的选择：

- 要不要有。没有金手指，读者看的是主角凭本事硬拼，每一次赢都实打实，但爽得慢，对布局的要求高。新手开书，有一个清楚的金手指更好写。
- 给多强。越强爽得越快，悬念越少，就越要在别处设限：代价、上限、成长的节奏、更强的对手。强到无敌的书，看点就得从「他能不能赢」换成「他怎么用」。
- 代价放在哪。可以长在金手指身上（用一次付一次），也可以放在世界的规矩里。没有任何代价，读者很快就不紧张了。
- 怎么成长。读者要看得见它一级级变强的路，盼头就在这条路上。
- 从哪来。来历不急着交代，但开书时心里要有一句真相，它往往就是全书的底，伏笔都从这里埋。

经验：

- 金手指最好和处境是一回事：处境是锁，金手指是钥匙。萧炎当了三年废柴，恰恰是因为戒指里的药老在吸他的斗气。
- 金手指、主角的驱动、背后的真相，能拧成一件事最好。封不觉没有恐惧，他玩游戏是为了找回恐惧，而恐惧是被伍迪封印的。
- 三句话说不清的金手指，读者记不住；复杂的规矩留到后面慢慢展开。
- 新手常栽的坑：金手指太全能，什么都能解决，后面没法写；和世界观不是一套规矩，读着违和。

## 四、核心循环

要做的选择：

- 每一圈主角反复做什么：换地图夺机缘、闯副本通关、接任务破灵异、破一个案子、推进一段感情……这决定了读者冲什么来，也就是常说的套路。
- 每一圈给读者什么满足：爽、悬、甜、惊、笑，要和题材许诺的一致。
- 每一圈带着主线走多远：一圈下来，主角离长远目标近了哪一步。
- 怎么一圈比一圈大：对手、舞台、赌注往上走，破法一圈比一圈不同。

经验：

- 开书前在脑子里把循环转三圈：第一圈、第五圈、第十圈分别在干什么。十圈之后还想得出新花样，长篇才撑得住；想不出来，要么循环太窄，要么世界观生不出足够的舞台。
- 循环的新鲜感来自换舞台、换对手、换破法，不是换名字。惊悚乐园的剧本类型一直在换，同一个「进剧本通关」才不腻。
- 每一圈都要带着主线往前一步，不然就成了流水账。恐怖屋每闯一次灵异，鬼屋就升一级，也离父母失踪的真相近一步。
- 新手常栽的坑：每一圈都是同一种破法（比如每次都是同样的打脸），读者十几章就腻；循环和主线脱节，故事一段段散着。

## 四块怎么咬在一起

- 处境加金手指，就是开局：处境把他逼到墙角，金手指第一次亮出来，第一圈循环开始转。
- 人设决定他在循环里怎么破局。同样是闯副本，封不觉靠脑子和不按常理出牌，换个人就是另一本书。
- 远处那一头要拧成一股：长远目标、金手指的真相、世界深处的秘密，好书里常常是同一件事。拧成了就是贯穿全书的主线；拧不上，书写到后面会散。
- 味道要统一：世界、主角、循环是一个味道。
- 卖点就是四块里最跟别人不一样的那一下。压成一句话，说给不看网文的人听，他想听下去，才算立住。

## 开书时定到什么程度

近处要清楚，远处一句话就够：

- 世界观：开局那片世界要清楚，远处和深处的秘密一句话。
- 主角驱动力：人设、处境、眼前目标要清楚，长远目标一句话。
- 金手指：能力和限制要清楚，来历和真相一句话。
- 核心循环：要清楚，而且能转很多圈。

模糊不等于空白，远处那一句话开书时就要有，前面才好埋伏笔。几十万字的世界开书时就想全，反而会乱，也会把作者累垮。

感情线和班底看题材：如果它们就是这本书的核心（言情里感情线本身就是循环），开书就要定。
