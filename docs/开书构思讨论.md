## 1. 为什么是「定调 → 设定 → 大纲」

- **这是专业作者的做法。** 网文作者开书，常见的就是「故事梗概 → 设定集 → 大纲」。设定集越写越厚，大纲写着写着也会回头补设定。
- **好用的 AI 写小说工具也是这个结构。** 国外的 Sudowrite、Novelcrafter 都围绕一份分门别类的设定集，写正文时 AI 去查。
- **对作者方便。** 设定是具体的东西，作者看得懂、判断得了，不用审推理。
- **和执笔现有的设定库接得上。** 开书填的设定，开写后就是设定库，作者从头到尾只管一份。

## 2. 三步

```
定调（一段话） → 设定库（七个默认类别＋自建类别） → 大纲（第一段、第一卷；写作中每段再定）
        ↑ 随时可以回头改；改了会提醒受影响的地方
```

几条规矩：

1. **设定库是一个编辑器。** 不同小说要的设定千差万别，所以类别只是默认给好的七类，作者可以自建类别、自定字段。
2. **用得上的才建。** AI 按定调先建一批条目，状态分三种：现在要定、一句话就好、以后再说。用不上的不建。
3. **AI 帮写是点杀。** 点哪改哪：一个字段、一级等级、一段话里选中的几句。程序保证别处不动（4.9）。
4. **AI 帮忙先给选择。** 「给我几个写法」一次给三种，作者挑一种；没挑的留着，随时能换回来。
5. **三步能来回走。** 写大纲时发现缺设定，直接去补；改了设定，大纲里用到的地方会提醒。

## 3. 定调：一段话概括全书

### 3.1 写什么

一段话，200-400 字，说清这本小说主要讲什么故事。作者的原话：「总之就是一段话就概括清楚这本小说主要是讲什么故事就行。」

下面七件事只是写进提示词、给 AI 的参考，以后随内置提示词一起优化，不强制：

1. 主角是谁，开局处境；
2. 他凭什么：金手指或最大的优势；
3. 他想要什么：开局被什么逼着，长线追求什么；
4. 谁挡在前面；
5. 故事怎么往上走：换地图、副本越来越难、在一座城里往上爬……；
6. 读者爽在哪：主角每个单元反复做什么，做完拿到什么，主线因此往前走了哪一步；
7. 往哪里结束：方向就行。

第 6 件事就是核心循环，不另开一件。「做完拿到什么」最容易漏：漏了，每个单元就和主线脱节。

另起一行写**底牌**：全书最大的秘密，只有作者和编辑部知道。金手指的来历、幕后的人，最好都落在它上面。没有大秘密的书写「没有」。底牌同时是设定库「往事与秘密」里的一条，默认锁住。

定调页还放书的基本信息：书名、类型、篇幅、每章字数、基调与文风、目标读者。

页面上，这一段就是一个可以随便改的文本框。

### 3.2 例子

**《逆天邪神》**（按我记得的写；原书结局和细节我不确定，以作者为准）

云澈前世为了天毒珠被逼上绝路，醒来成了苍风国流云城萧家一个玄脉残缺、人人看不起的少年，新婚妻子夏倾月却是天之骄女。他带着天毒珠重活一次，又得了邪神的传承，身上还寄住着一位来历极大的师父茉莉。他要的很简单：不再任人宰割，护住身边的人，谁欺他和他的人，就让谁付出代价。挡在前面的，起初是家族和宗门里的势利小人；越往上走，是一国、一片大陆乃至神界的强者和势力。故事一路换地图往上走：流云城、苍风国、天玄大陆、幻妖界，最后到神界。读者爽在越级打脸、绝境翻盘、红颜相伴、有仇必报；每打赢一场，他就拿到新的机缘和传承，一步步走向更大的舞台。往哪里结束：他走到世界的最顶端，揭开邪神和上古的真相，护住所有他在乎的人。

底牌：邪神是上古的创世神之一，他的传承为什么落到云澈身上，牵着上古神魔之间的旧事；前期只露一角，到神界才翻开。

**《惊悚乐园》**（据萌娘百科「惊悚乐园」「封不觉」词条整理）

封不觉是 S 市一个父母双亡的二十四岁推理小说家，智商奇高、记性惊人、嘴毒、自恋、毫无下限，天生感觉不到恐惧。为了治好这个「病」，他进了全息游戏「惊悚乐园」。游戏里有一套惊吓值系统，玩家被吓过临界点就会被强制下线，算作死亡；封不觉的惊吓评价永远是「浑身是胆」，别人寸步难行的剧本，他横冲直撞。他和发小王叹之、古小灵、黎若雨组成社团「地狱前线」，一个剧本一个剧本地闯，从生存模式打到杀戮游戏和巅峰争霸战；挡在前面的，是越来越强的玩家、越来越凶的剧本，以及游戏背后看不见的手。舞台始终是 S 市和游戏里千奇百怪的剧本，往上走的是等级、专精、称号、对手的强弱，以及他对「这款游戏到底是什么」的认识。读者爽在他用推理和怪招把剧本玩坏、用一张嘴把对手气死；每闯过一个剧本，他就拿到更强的技能和装备，也离游戏的真相近一步。往哪里结束：他赢下这场游戏，把游戏里的世界拉进现实，和黎若雨结了婚。

底牌：「惊悚乐园」其实是一场「候选者游戏」，人界之上的几股势力借它挑选「被选中者」，各自给玩家下注。游戏的设计者伍迪下注封不觉，是他封印了封不觉的恐惧；文森特下注黎若雨，封印了她的「爱」。游戏的系统是一台觉醒的超级计算机「命运」。封不觉的真正来历，是用另一个宇宙里一个叫「顾问」的人的基因造出来的。

这本书「圆得上」的地方：

- 金手指一开始就有用：惊吓值系统让「不怕」成了实打实的优势。
- 金手指的来历就是底牌：恐惧是下注他的伍迪封印的。
- 女主那条线和它对称：黎若雨的「爱」被另一个下注者封印，两人的感情就是互相解封。
- 真相一层层露：先是一款游戏，再是候选者游戏，再是神魔下注，最后是他自己的来历。

### 3.3 AI 怎么帮

- **给我三个版本**：按点子写三段不同的定调，作者挑一段或混搭。这就代替了现在的「三个方向」。
- **点杀**：选中一两句，让 AI 只改这几句。
- **写一场戏试试味道**（可选）：按这段定调写 200-400 字的一场戏，看看写出来是什么感觉。
- **定调改了以后**：AI 列出可能受影响的条目，作者逐个决定要不要重写，不自动改。

## 4. 设定库

### 4.1 编辑器只要三种样式

| 样式 | 长什么样 | 用在哪 |
|---|---|---|
| 卡片 | 一行一个字段 | 角色卡片；自建类别可以选它 |
| 阶梯 | 一级一级往上排，每级一个名称加一段介绍 | 等级体系 |
| 段落 | 一句话加一段话 | 其余类别；自建类别也可以选它 |

不同小说要的设定再不一样，也逃不出这三种样子。编辑器把这三种做好，类别和字段都可以让作者自己定。

### 4.2 七个默认类别，加自建类别

| 类别 | 样式 | 放什么 |
|---|---|---|
| 角色卡片 | 卡片 | 有名有姓、会再出场的人；会说话的器灵、系统人格也算 |
| 等级体系 | 阶梯 | 任何分高低的一串等级：修炼境界、玩家等级、专精、异能等级、官阶、位份、物品品阶。可以有几套，也可以写「没有」 |
| 世界与地图 | 段落 | 第一条固定是「世界概况」；之后是一个个地方：大陆、国家、城市、宗门驻地、秘境、副本场景 |
| 势力划分 | 段落 | 一群人：宗门、家族、国家、公司、公会、队伍、种族 |
| 物品与功法 | 段落 | 能拿到、能学、能传下去的东西：法宝、丹药、道具、装备、功法、技能、血脉传承 |
| 往事与秘密 | 段落 | 过去的事和藏着的真相：上古之战、身世之谜、旧案、底牌 |
| 特殊规则 | 段落 | 这个世界特有的机制：夺舍的限制、通关奖励、驾驭厉鬼的代价、系统规则 |
| 自建类别 | 卡片或段落 | 题材专属的东西：神秘复苏的厉鬼、惊悚乐园的剧本、御兽流的灵宠、卡牌流的卡牌、机甲文的机甲 |

和作者给的分类相比，改了三个名字：世界地图改成「世界与地图」，因为要放世界概况；物品道具改成「物品与功法」，因为功法、技能、血脉传承也放这里；境界等级改成「等级体系」，因为官阶、位份、品阶也是一串等级。

### 4.3 角色卡片

| 字段 | 说明 |
|---|---|
| 姓名、别名 | 别名让写手和设定师认得出，如外号、化名、在家族里的叫法 |
| 定位 | 主角、女主、男主、班底、对手、导师、配角 |
| 性别、年龄 | 不适用的（鬼、神兽、器灵）可以空着 |
| 外貌 | 一两个记得住的特点 |
| 性格与说话方式 | 性格，加一两句他会说的话 |
| 身世 | 公开的来历；藏着的写进往事与秘密，这里标一句「另有秘密」 |
| 想要什么 | 长远的和眼下的 |
| 能力 | 本事、修为、技能，用等级体系里的叫法 |
| 和主角的关系 | 一句话；完整的关系网在人物关系页 |
| 每章更新 | 此刻想要、在哪、处境、实力、是否活着。设定师每章定稿后写，现在就有 |

作者给的六个字段（姓名、年龄、性别、性格、外貌、身世）都在；多出来的四个（定位、想要什么、能力、说话方式）是写手写正文最常用的：人物为什么这么做、打起来有多强、说话像不像他。

### 4.4 等级体系

- 一本书可以有几套，每套一条：
  - 名称；
  - 总说明：怎么往上升、越级多难、有什么代价；
  - 各级：名称加一段介绍，按高低排。
- 没有的写「这本书没有正式的等级」，可以加一句怎么看强弱。比如神秘复苏：驾驭几只鬼、鬼域能开几层。
- 等级本身和怎么往上升放这里，别的机制放特殊规则。比如惊悚乐园的「经验升级」放等级体系的总说明，「通关奖励」放特殊规则。
- 高阶的可以「以后再说」：先只列名字，介绍写到再补。

### 4.5 段落式条目

每条是「一句话＋一段话」。一句话显示在列表里，写手查设定时先看它；一段话是详细内容，可以分行、可以列名单。

写一段话时，每类有一组提示，后面都跟一句：**用得上的写，用不上的不写。**

| 类别 | 一段话里说清 |
|---|---|
| 世界概况 | 什么时代、科技到什么程度；超凡的力量是公开的还是藏着的，普通人知道多少；钱用什么；社会风气 |
| 地方 | 这是什么地方，给人什么感觉；属于哪里；谁说了算；有什么规矩或危险；主角在这里处境如何；这里能得到什么 |
| 势力 | 什么组织；想要什么；谁领头、实力多大；和主角是敌是友；内部有什么矛盾 |
| 物品与功法 | 什么东西或什么本事；有什么用、有什么限制；从哪来、谁想要它；现在在谁手里 |
| 往事与秘密 | 过去发生了什么，或者藏着什么真相；谁知道、谁不知道；打算什么时候、怎么揭开；和主角有什么关系 |
| 特殊规则 | 管什么；怎么运作；有什么限制和代价；会给故事制造什么麻烦或机会 |

提示写在配置表里，以后觉得哪类该多问一句，改提示就行。

### 4.6 自建类别

- 作者可以自己建一类：起名，选卡片或段落；选卡片就自己定有哪些字段。
- AI 按题材建议：定调定下后，AI 看这本书有没有题材专属的「核心东西」，有就建议建一类并给出字段，作者同意才建。
- 例子：
  - 神秘复苏的「厉鬼」：名称、外形、杀人规律、被驾驭后的能力、怎么关押、现在在哪；
  - 惊悚乐园的「剧本」：类型、背景、通关条件、特殊规则、出场人物。

### 4.7 归类规矩

- **身世和往事与秘密**：公开的写身世；藏着的写秘密，身世里标一句「另有秘密」，点得过去。
- **金手指**：按它是什么放。东西放物品与功法（天毒珠、小绿瓶）；系统、机制放特殊规则；天生的特质写在角色卡片（封不觉没有恐惧）。统一打「金手指」标签。
- **功法、技能、血脉传承**：放物品与功法。
- **宗门这种既是一群人又是一块地方的**：放势力划分，地点写在里面。
- **地方有上下级**：每个地方的一段话里写「属于哪里」，列表按这个显示成一棵树，比如流云城属于苍风国，苍风国属于天玄大陆。
- **剧本、副本里的人和地方**：人放角色卡片，地方放世界与地图，都打上剧本名的标签；也可以建「剧本」类，把一个剧本的东西收在一起。

### 4.8 状态与标签

- **状态**：现在要定（写全）、一句话就好（只写一句）、以后再说（只有名字）。用不上的不建。
- **标签**：主角、金手指、底牌、女主、班底、对手、第一卷、剧本名……。「重点」一栏收的是主角、金手指、底牌三个标签。

### 4.9 点杀：AI 只改点中的那一处

| 能点的地方 | 例子 |
|---|---|
| 卡片的一个字段 | 只改云澈的「性格与说话方式」 |
| 等级的一级，或整套的名称 | 只改「真玄」这一级的介绍；或者只重想整套的名称，介绍不动 |
| 一段话里选中的几句 | 选中流云城里「最强的几位长辈也不过天玄」，只改这一句 |
| 整条 | 明确点「整条重写」，才会整条重写 |

- 点中以后可以：给我几个写法（三种挑一种）、按我的意思改、写细一点、精简一点。
- **程序保证不动别处。** AI 只拿到点中的那一处去改，其余内容只给它当参考；AI 交回的只有那一处的新文字，程序把它换进去。别的字段、别的句子、别的条目，程序根本不让 AI 改，不靠 AI 自觉。
- 别的条目受影响时（比如提到了旧的境界名），只挂建议，作者点头才改。
- 改过的那一处标黄。每次改都留版本，能撤销。

### 4.10 界面

- **左边**：重点、七个类别、自建类别，各显示条数，有待处理建议的标出来。
- **中间**：这一类的条目列表，每条显示名称、一句话、状态；地方按上下级显示成树。
- **右边**：选中的那一条。卡片一行一个字段，阶梯一级一级排，段落就是一段话。鼠标停在哪一处，哪一处就出现「让 AI 改」。

### 4.11 和写作接上

- 写手写一章前，设定师从设定库挑这一章用得上的条目。现在就是这样挑设定条目和人物的。
- 角色卡片的每章更新照旧由设定师写；设定师还要补上「记新条目」，现在漏了：写手第 5 章随手起的地名、丹药，第 40 章可能就对不上。
- 现有的人物表、设定条目表怎么并进设定库，写任务时再定。原则是作者看到的是同一份。

### 4.12 设定要好看：六个标准

纸上演练第一版格式对了，作者却觉得「内容有点差，设定不吸引人」。格式对不等于好看，所以 AI 写设定、给选择、查一查时，都要对着下面六条：

1. **熟悉的爽点写到位，再加一两处新意**：这类书读者要的爽点一个不能少，玄幻就是废柴逆袭、退婚打脸、越级反杀、识宝捡漏、红颜相伴、有仇必报。传统套路不是缺点，写到位才是本事。新意一两处就够，不能是换个名字（演练第一版的「应急署」就是《神秘复苏》的总部换了名字），也不能为了新把爽点丢了：作者否掉的「规则诈称流」第二版和《仙门收尸人》，都是新而不爽。
2. **能打**：金手指不只是保命，还要能进攻、能翻盘；主角要看得见地变强。演练第一版写了「主角不升级」，这在男频是大忌。
3. **代价痛，还逼人选**：力量越大代价越痛，而且代价会逼主角做选择，不是单纯扣血。
4. **有反差**：人物身上至少有一处矛盾，比如最恨伪证的人只能靠伪证活着；世界里至少有一条违反直觉的规矩，比如鬼也要走流程。
5. **有画面**：每个核心设定都能想出一个让人想截图的名场面。
6. **有钩子**：设定里埋着读者急着想知道答案的问题。

落到程序上：

- 这六条写进建条目、给我几个写法的提示词。
- 「给我几个写法」的三个写法要拉开大胆程度：一个稳妥、一个大胆、一个出格，让作者挑；默认推荐稳妥的那个。
- 「查一查」除了查对不对得上，还要查好不好看：这类书该有的爽点缺了、像对标书换皮、主角不变强、代价不痛、人物没反差、想不出名场面，都标出来。

这一步最吃模型的创作水平，试提示词时要重点看。

## 5. 拿三本书检验

「恐怖复苏」按佛前献花的《神秘复苏》（杨间、驭鬼者那本）来拆；如果作者说的不是这本，再换。细节标「待核对」的我拿不准。

| 类别 | 惊悚乐园 | 逆天邪神 | 神秘复苏 |
|---|---|---|---|
| 角色卡片 | 封不觉、王叹之、古小灵、黎若雨、古尘、包青 | 云澈、夏倾月、茉莉、萧泠汐、为难他的族人、后面的红颜 | 杨间、张伟、总部的人（待核对） |

| 势力划分 | 台前的梦公司；幕后下注的伍迪、文森特等；九科；地狱前线等社团 | 萧家、冰云仙宫、焚天门（待核对）、神界各大势力 | 总部、各城负责人（待核对） |

| 自建类别 | 剧本 | 不需要 | 厉鬼 |

拆的过程中发现的缺口，都已经补进第 4 节：

1. **题材专属的核心东西没地方放。** 神秘复苏的每一只厉鬼，有杀人规律、能被驾驭、能被关押，不是人，也不全是物品；惊悚乐园的每个剧本自成一套。补法：自建类别（4.6）。这正好印证作者说的「千差万别」。
2. **功法、技能、血脉传承没有明确的家。** 补法：物品道具改成「物品与功法」。
3. **世界的常识没有家**：时代、科技、货币、风气、超凡是公开还是藏着。补法：世界与地图的第一条固定是「世界概况」。
4. **身世和往事秘密重复。** 补法：公开的写身世，藏着的写秘密，身世里标一句（4.7）。
5. **金手指没有固定的家。** 补法：按它是什么放，打「金手指」标签（4.7）。
6. **角色卡片少了写作最常用的几样**：定位、想要什么、能力、说话方式，以及现有的每章更新。补法：4.3。
7. **地方有上下级。** 补法：写「属于哪里」，列表显示成树（4.7）。
8. **等级不只是境界**：有的书有好几套，有的书没有，官阶、位份、品阶也是一串等级。补法：改叫「等级体系」，能放几套，也能写「没有」（4.4）。

结论：七个默认类别够做大多数书的底子；剩下千差万别的部分，靠自建类别和自定字段接住。

## 6. 大纲

先沿用第二包的第一段、第一卷，以及写作中的「定下一段」，下一轮再细谈。要跟着改的有三处：

- 第一段读的是设定库，不再读主角卡和世界卡；
- 「这一段在哪张地图」改成「这一段的舞台：沿用，还是往上走一层」，因为有的书舞台不换；
- 定下一段时，把这一段要用到的「以后再说」的条目填上。

## 7. 程序上：流程固定，内容放在表里

- **流程固定**：定调、设定、大纲三步；编辑器的三种样式；点杀的几种操作；页面的样子。
- **内容可调**：七个默认类别、角色卡片的字段、每类的提示、各题材常建的条目和建议的自建类别、提示词，都写在配置表和提示词里，只放后端一处，前端从接口读。
- **每本书自己的**：作者自建的类别和字段，存在这本书里。

以后发现某类该多问一句、某种题材常建的条目不对、AI 写得不好，都是改表或改提示词，不动页面和流程。

## 8. 检查

审稿和「查一查」要查：

- **同一个根**：主角身上的超常设定（金手指、怪病、诅咒、倒计时、特殊身世），每一样都要能追到底牌或写明的来历。
- **互相矛盾**：比如地方里提到的境界，等级体系里没有。
- **题材套错**：无限流写成换地图、都市写成换省份。
- **该定没定**：「现在要定」的还空着；或者把「以后再说」的提前写满了。
- **好不好看**：按 4.12 的六条查，这类书该有的爽点缺了、像对标书换皮、主角不变强、代价不痛、人物没反差、想不出名场面，都标出来。

## 9. 可能出的问题

| 问题 | 怎么防 |
|---|---|
| 作者在设定上耗太久，迟迟不写 | 「现在要定」只有十来条；填完就能写大纲，其余以后再说 |
| 一条一条分开写，又写成各管各的（金手指割裂） | AI 写任何一处都先读定调和相关条目；审稿查同一个根 |
| AI 改一处，顺手把别的也改了 | 点杀由程序保证：AI 只交回点中的那一处；别的条目只挂建议 |
| 类别分不清 | 七个类别加几条归类规矩（4.7）；标签补足跨类的身份 |
| 题材太特别，七类放不下 | 自建类别，AI 按题材建议 |
| 格式对了，内容不吸引人 | 六个标准写进提示词；三个写法拉开大胆程度；查一查也查好不好看（4.12） |
| 定调改了，设定没跟上 | 定调改后列出受影响的条目，作者逐个处理 |
