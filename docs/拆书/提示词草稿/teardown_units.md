单元是一个完整的小故事，几章到十几章：一件事找上门，主角应对，读者叫好的那一下，做完拿到点什么、主线往前走一步。上一件事了结、下一件事找上门的地方，就是两个单元的分界。

要求：
1. 从第 {{first}} 章开始往后，一个挨一个划，不重叠、不跳章；每个单元写起止章号 first、last。
2. 每个单元：
   - title：4–8 个字，像原作者自己给这段故事起的名字（比如「退婚风波」「拍卖会」「夜探东院」）；
   - text：一段话，100 字以内，按这个顺序写四句，用分号隔开：什么事找上门；主角怎么应对；读者叫好的那一下；做完拿到什么、主线往前走了哪一步。只写原文里有的，不评价。
     这是原作者动笔前给自己写的大纲，不是剧情梗概：每句只说这件事是什么，数字、对白、小动作、配角的反应都不写（那些在章纲里）。人名照原文写，不要换成「主角」「女生」「班花」（书里常常不止一个女生）。
     例（《斗破苍穹》开头）：不要写成「纳兰嫣然带着云岚宗长老上门，当着萧家众人提出退婚，萧战脸色铁青，萧炎拍案写下休书，约定三年后上云岚宗」；要写成「萧炎最落魄时，未婚妻纳兰嫣然上门退婚、当众给他难堪；萧炎不求不忍，反手自己写休书；休书甩出去、立下三年之约；读者有了一个要追很久的期待，主线从这里开始」。
3. 一个单元超过 20 章，多半是两件事，拆开；一两章的过渡并进前后的单元，不单独成一个。
4. 最后一件事还没了结（后面的章没读到），就不要硬收：这几章不归进单元，open_from 写从第几章起还没收尾。
