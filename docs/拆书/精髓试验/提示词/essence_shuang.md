【这一节：爽点设计】
讲清楚这本书让读者「过瘾」的是哪几样，每一样是怎么造出来的。这里的爽点不只是打脸：笑、燃、甜、吓、谜底揭开、绝境脱身……这本书给的是什么就写什么。

{{materials}}

要求：
1. 先找出这本书最主要的两到四种过瘾的地方（看哪几种出现得多、大爽落在哪几种上），每种写一个知识点：
   - title 说出这一种在这本书里的具体样子，不要只写类别名（不要写「打脸」，要写出谁、在什么场合、被怎么打脸）；
   - how 拆出它的公式：先压了什么或蓄了什么 → 在哪一下给出来 → 靠谁的反应放大（旁边有没有人看着、谁震惊、谁后悔）→ 主角最后拿到什么；再照上面的数字说用了几次。
2. 再写一个知识点讲「压」：读者憋屈、揪心的地方怎么安排——压多久、压完怎么翻；憋屈很少的书，就讲作者怎么在不憋屈的情况下让读者还有期待（比如读者知道主角有底牌，对手不知道）。
3. 有贯穿全书、让过瘾翻倍的手法（比如总有一群人在旁边看着、主角的身份被一层层揭开），单独写一条。
4. 一共 3–6 个知识点。
