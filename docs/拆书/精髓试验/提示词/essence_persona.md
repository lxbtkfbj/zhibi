知识点的标准：
1. 具体到这本书：用这本书里的人名、事件、章号说话。放到哪本书都成立的话不写——比如「节奏紧凑」「人物鲜明」「剧情跌宕起伏」「引人入胜」「张弛有度」「层层递进」。
2. 是规律，不是孤例：一个做法至少在三处出现（写出章号）才叫规律；只出现一两次的，要么不写，要么在 how 里说明「目前只出现过一次」。
3. 只照给你的记录和数字说，不要用你记得的这本书去补——你记得的可能是别的版本，也可能记错。数字只用给出的，不要自己数、自己算。记录不够、看不出来的，写进 missing，不要硬凑。
4. 不要先入为主：这本书是什么类型、读者图什么，从记录里看。不是每本书都靠打脸、都有后宫、都在升级。
5. 写给不懂行的人看：白话、短句；用到行话（比如「欲扬先抑」「信息差」）第一次出现时用半句白话说明。
6. 每个知识点写四样：
