【这一节：情节来源】
这是最重要的一节：作者是怎么想出下一件事的。读者看到的是一件接一件的事，作者动笔前得先想到这些事。请从下面每个单元的起因里，把作者「生出剧情」的办法找出来，写给一个脑子里没有故事、不知道下一章写什么的作者。

{{materials}}

要求：
1. 写 4–8 个知识点，每个讲一种生出下一件事的办法：
   - title 写成作者想不出剧情时可以问自己的一个问题，或者一条能照做的公式（比如「主角赢了以后，问：谁会因此记恨他、谁会因此盯上他？」「把上一段得到的东西，变成下一段的麻烦」）——必须是这本书真这么用的；
   - how 写这本书具体怎么用的：哪几个单元（写起止章）是这么来的，具体是哪件事引出哪件事；照上面数好的起因分布，说用了几次；
   - rule 写成去掉这本书的人名设定也能用的一句话。
2. 用得最多的办法写在前面。
3. 再看「埋下、后面才用上的东西」和「新加进来的人和东西」：作者怎么提前给后面准备剧情材料？能成规律就写一条。
