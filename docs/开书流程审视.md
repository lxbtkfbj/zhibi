# 开书流程审视（讨论稿 v3）

> 状态：讨论稿，2026-10-16。
>
> - **v1**：作者用真实模型试开一本借用《我有一座恐怖屋》设定的新书，发现概念里缺了「主角的驱动力」，并指出之前只排了先后顺序，没想清楚每一步要回答什么。v1 按「每一步必须回答什么」重排了开书步骤。
> - **v2**：作者又指出，作者不会在开写前把整本书的剧情想好，都是写一点想一点。v2 据此把每道必答题分成「开写前定」和「写到再定」：开书只定到第一段，后面每一段写到之前再定。
>
> - **v3**：细化③④。③改为「世界、第一张地图和这里的人」，第一段的配角从④挪到③；④增加「这一段的目标」「这一段让读者等什么」「这一段揭开什么」；③④同时作为写作中「定下一段」的模板。
>
> 和作者逐步确认后，再改设计说明、写实施任务。

## 1. 两个问题

### 1.1 按文件分块，不按问题分块

之前的五块是按 AI 产出的文件来分的（概念、主线骨架、设定、总纲、卷纲），不是按作者要回答的问题来分的。

- 主角的驱动力散在三处，而且来得太晚：概念里的「主角钩子」、关键节点里的「主角成长弧」、设定里人物的「最想要什么」。关键节点生成时，主角为什么要往前走还没定。
- 有些开书必须想清楚的事，没有任何一步负责：主角每个单元在干什么（核心循环）、主角的底线、对手想要什么、世界的核心谜团。
- 页面按字段堆，作者看不出这一步定下了什么、还缺什么。

### 1.2 开书要求定得太多

现在写第 1 章之前，要先产出：

- 全部 8-14 个关键节点，每个都要写前提和后果；
- 全书每一卷的卷卡片；
- 每条线索在每一卷的节拍；
- 5-12 条长线伏笔、2-6 条长线期待。

这等于要求作者开写前想好整本书，不现实。

连载网文的常态是「粗纲 + 细纲滚动」：大方向心里有数，近处想清楚，远处写到再说，还要根据写出来的效果和读者反应随时调整。写作阶段其实已经在滚动——每卷写到之前拆卷纲，每个单元写到之前出章纲——问题出在开书这一头太重。

## 2. 三条原则

### 2.1 三件套要咬合

三件套是：

- 驱动力：主角为什么往前走；
- 金手指：凭什么走得动；
- 核心循环：每个单元怎么走。

三样必须是一套，互相咬合。

- **咬合的例子**（虚构）：
  - 驱动力：找回被人偷走的十年记忆；
  - 金手指：能读出旧物上残留的记忆；
  - 核心循环：接委托、读旧物、破案，每个案子都带回一块自己的记忆碎片。

  读者每个单元既有破案的爽，也看着主线往前走。
- **脱节的例子**：驱动力是复仇，金手指是种田系统，核心循环是经营农场。复仇只在开头结尾出现，主线成了摆设。

作者举的例子都咬合。驱动力按作者的描述是：

- 云澈：为了身边的红颜不得不变强；
- 陈歌：寻找失踪的父母；
- 封不觉：找回自己的恐惧。

### 2.2 近清远粗

每道必答题都标明什么时候定：

- **开写前定**：第 1 章就会用到的，或者决定「这本书是什么」的。
- **写到再定**：远处的剧情、后期的地图和人物、金手指后期的能力、结局的细节。

模糊不等于空白。远处也要有一句话的方向，比如结局大概怎样、长线追求的终点是什么，不然前面没法埋伏笔、立期待。方向随时可以改。

### 2.3 谜面现在定，谜底写到再定

驱动力和核心谜团常常是一个谜，比如父母为什么失踪。

- 开写前只需要定谜面，也就是读者从开局就好奇的那个问题；谜底可以先不知道。
- 谜底必须在揭晓前几卷定下来，否则伏笔接不上，容易烂尾。系统会在揭晓节点临近时提醒作者定谜底。

## 3. 新的流程

开书只定到能开写：

| 步骤 | 回答的核心问题 |
|---|---|
| 选方向 | 大概往哪写。方向卡增加「驱动力」「核心循环」两行速写 |
| ① 定调 | 这本书是什么、写给谁、凭什么好看 |
| ② 主角 | 他是谁、想要什么、为什么、凭什么 |
| ③ 世界、第一张地图和这里的人 | 世界的基本规则是什么；第一张地图上谁说了算、和谁打、身边有谁 |
| ④ 第一段怎么走与全书方向 | 开篇怎么开、这一段想做成什么、走到哪里结束、结局大概往哪去 |
| ⑤ 第一卷 | 第一卷拆成哪些剧情单元 |

写作中，每一段开写前先「定下一段」（第 5 节）。

这里的「段」，指从一个关键节点走到下一个关键节点的那一段剧情，通常对应一张地图、一到三卷。

和 v1 相比：v1 的「③ 世界与对手」「④ 关键节点」「⑤ 人物群像」「⑥ 填中间」，开书时只做近处那一部分，合并成上面的③④；远处的部分挪到写作中逐段去定。开书从七步回到五步。

## 4. 开书每一步的必答题

### ① 定调（全部开写前定）

| 必答题 | 要答到什么程度 |
|---|---|
| 定位 | 什么题材；男频还是女频；这类读者爱看什么、最讨厌什么。作者提到对标作品时，写清借鉴它什么、哪里要不一样 |
| 一句话故事 | 50 字内：谁、想要什么、最大的阻碍、和别的书哪里不一样 |
| 核心卖点 | 2-3 个，具体到读者会为哪种场面叫好 |
| 核心循环 | 主角在一个个剧情单元里反复做的那件事，以及读者每个单元能拿到的爽感 |
| 基调与文风 | 轻松还是压抑、幽默还是冷峻、节奏快慢；人称 |
| 篇幅与书名 | 篇幅只定大概；书名以后可以改 |

### ② 主角

| 必答题 | 要答到什么程度 | 什么时候定 |
|---|---|---|
| 起点 | 身份；开局处境有多低多难；读者为什么会代入他 | 开写前 |
| 驱动力·开局动机 | 开局发生了什么，逼他不得不行动 | 开写前 |
| 驱动力·长线追求 | 贯穿全书或大半本的追求，如找人、复仇、守护、找回、证明、求生、登顶。要具体，不能只是「变强」；是个谜的话先定谜面 | 开写前（方向即可） |
| 驱动力·情感根源 | 他为什么在乎：爱谁、欠谁、怕什么、缺什么 | 开写前 |
| 驱动力·怎么升级 | 舞台变大后追求怎么变大，会不会换成新的追求 | 写到再定：每段开写前检查一次 |
| 性格、底线与说话方式 | 2-3 个核心性格加一个反差；做事风格；绝不做的事；说话是什么样子 | 开写前 |
| 金手指·现在 | 一句话核心规则；第一阶段能做什么；限制；谁知道 | 开写前 |
| 金手指·以后 | 后期怎么成长；来历是什么（可以先当成谜） | 写到再定 |
| 软肋 | 最大的缺点或心结 | 开写前 |
| 成长的终点 | 最后变成什么样的人 | 一句方向即可，写到再细化 |
| 在乎的人 | 开局就在身边的那几个人；后面登场的到时候再加 | 开写前（只限开局的） |
| 咬合检查 | 驱动力、金手指、核心循环是不是一套 | 开写前 |

### ③ 世界、第一张地图和这里的人

> 作者重点看：第一段的对手、这里的人。

| 必答题 | 要答到什么程度 | 什么时候定 |
|---|---|---|
| 世界的表里 | 超自然的力量是公开的还是藏着的，普通人知道多少。修仙玄幻通常人人皆知，都市灵异多半藏着；这决定主角能不能公开出手 | 开写前 |
| 力量规则 | 升级靠什么（修炼、资源、积分、任务……）；限制和代价；低阶几层叫什么、差距多大（越一级有多难）。按题材换说法：修仙的境界、灵异的鬼怪等级、无限流的副本难度、都市的财富与地位 | 开写前；往上的写到再定 |
| 第一张地图 | 谁说了算、谁和谁有仇；天花板有多高（最强的是谁、到什么程度）；这里特有的规矩；主角开局在哪一层；这里能拿到什么（机缘、地位、名声、资源） | 开写前 |
| 第一段的对手 | 开篇压着主角的小麻烦是谁；这一段的大对手是谁、想要什么、为什么和主角撞上、手里有什么牌、会怎么谋划 | 开写前 |
| 这里的人 | 第一段会登场的女主、伙伴、导师（②里主角在乎的人自动带上）：各自想要什么、性格、说话方式、和主角之间的张力 | 开写前 |
| 远处的影子 | 后面几张地图的名字和一句话（可以空）；终极敌人的影子（传说、阴影或代理人）；核心谜团的谜面 | 谜面开写前定；其余写到再定 |

合格标准：

- **第一张地图要小而具体**：势力三四个，要紧的人物七八个以内。名字一多，新读者就记不住。
- **规则要能生出剧情**：限制会逼人冒险，资源稀缺会引来争夺；不要写成说明书。世界观只露剧情用得到的那一角，其余写到再露。
- **对手要有自己的目标**，不是专门来欺负主角的；他要比主角强，并且先赢一次，主角翻盘才有分量。
- **远处的影子要在前期露一面**，让读者知道上面还有更大的东西。

### ④ 第一段怎么走与全书方向

> 作者重点看：开篇、这一段的目标、这一段的终点。

| 必答题 | 要答到什么程度 | 什么时候定 |
|---|---|---|
| 开篇 | 第一章从哪个场面切入（从冲突或异常切入，不从背景介绍开始）；前 3 章主角被什么压着、第一个小爽点落在哪一章、金手指第几章露头；第 3 章结尾的钩子 | 开写前 |
| 这一段的目标 | 主角这一段想做成的那件事。要具体，有期限或有对手，比如「三个月后的外门大比拿到名额」，而不是「变强」；还要说清做成它为什么能离长线追求更近 | 开写前 |
| 这一段让读者等什么 | 一件读者明确在等的事（约定、比试、倒计时、要揭穿的身份），它就是这一段的长线期待 | 开写前 |
| 这一段揭开什么 | 核心谜团露出哪一角，同时冒出什么新问题；这一段用得到的信息差（谁知道什么） | 开写前 |
| 这一段的终点 | 第一个关键节点：发生什么、之前得先有、之后变成（主角的追求、处境、地图有没有变）。它就是这一段的最高潮 | 开写前 |
| 人物出场 | ③里的人分别在什么时候登场、关系怎么变（人物锚点） | 开写前 |
| 分卷 | 这一段分几卷（通常一到三卷）、每卷多少章；只给这几卷写卷卡片 | 开写前 |
| 全书方向 | 结局方向一句话：长线追求最后怎样、主角最后变成什么样的人。作者已经想到的远景节点钉上，没有就空着 | 结局方向开写前定（可以改）；远景节点可选 |

### ⑤ 第一卷

同现在：把第一卷拆成剧情单元。另外两条要求：

- 每个单元都要能看出核心循环在转；
- 写清主角这一卷想要什么，它和这一段的目标是什么关系。

## 5. 写作中：每段开写前「定下一段」

③④其实是一个「规划一段」的模板：开书时用它规划第一段；写作中每段快写完时，主编用同一套题规划下一段。区别只是把「第一张地图」换成「下一张地图」；不换地图就沿用。

**什么时候触发**：

- 当前这一段快写完时：写到这一段的最后一卷，拆它的卷纲之前；
- 要拆的那一卷还没有明确的终点节点时。

**主编先提「下一段规划」**，回答③④的题，另外加三项：

- 主角的追求要不要升级或更换；
- 金手指下一阶段解锁什么；
- 临近揭晓的谜团，定下谜底。

作者之前钉过的、落在这一段的远景节点，原样用上。

**作者处理**：作者确认，或者点「交给编辑部定」。也可以在本书设置里关掉这一停，自动通过，跟现在的卷纲拍板开关一样。确认之后照常拆卷纲。

**全书地图上的显示**：

- 已经写完的段、正在写的段、已规划的段、还没规划的段，各有自己的样子；还没规划的远处显示为「下一段：写到再定」。
- 作者随时可以往远景里加想法并钉上，编辑部规划到那里时会用上。

## 6. 页面

- **按题分组**：每一步的页面按必答题分组，小节标题就是问题本身，例如「他为什么要往前走」。答得不合格的题，由程序检查或审稿标出来。
- **作者重点看**：每一步标出最值得作者看的两三道题，其余可以扫一眼就过。作者不是专业写手，不必每道题都细看。
- **标明什么时候定**：每道题旁边标「开写前」或「写到再定」。「写到再定」的题显示「先空着，写到这里时主编会来问你」。
- **概念页现在的排版问题**：
  - 右栏把五样性质不同的东西竖着堆在一起，左栏只有卖点，两栏一长一短；
  - 舞台阶梯「A → B → C」按普通段落折行；
  - 程序算出来的篇幅灰字和可编辑内容混在一起；
  - 编辑状态的灰底和铅笔图标贴在栏边。

  按题分组后：短的事实用「一行一项」的紧凑表，舞台阶梯画成一节节台阶，主角的内容移到②。

## 7. 已定与待定

已定：

- 开书只定到第一段，后面每一段写到之前再定（作者已同意）。
- 核心循环每本书都要有。以感情为主的书，循环就是感情的推进，比如误会、靠近、甜、新的阻碍（设计决定）。
- ③④按上面的题来（设计决定，作者已看过）。

待定：

- 「定下一段」默认要不要停下来等作者确认。
- ⑤第一卷和「定下一段」的细节过完以后，再改设计说明、写实施任务。
