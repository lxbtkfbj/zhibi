# 开书流程审视（讨论稿）

> 状态：讨论稿，2026-10-16。作者用真实模型试开一本借用《我有一座恐怖屋》设定的新书，发现概念里缺了「主角的驱动力」，并指出：之前只排了先后顺序，没想清楚每一步到底要回答什么。本稿逐步列出开书每一步的「必答题」，和作者逐步过一遍、定下来以后，再改设计说明、写实施任务。

## 1. 问题出在哪

之前的五块是按 AI 产出的文件来分的（概念、主线骨架、设定、总纲、卷纲），不是按作者要回答的问题来分的。结果有三个后果。

**主角的驱动力来得太晚，而且散在三处。**

- 概念里只有一句「主角钩子」。
- 关键节点里有「核心矛盾」和「主角成长弧」。
- 设定里每个人物有一个「最想要什么」。

关键节点生成的时候，主角为什么要往前走还没定下来，主线自然就空。

**有些开书必须想清楚的事，没有任何一步负责：**

- 主角每个单元在干什么（核心循环）；
- 主角的性格底线；
- 终极敌人想要什么；
- 世界的核心谜团。

**页面按字段堆。** 作者看不出这一步「定下了什么、还缺什么」。

改法：每一步先列「必答题」，也就是这一步必须回答清楚的问题，并附合格标准。AI 按题作答，作者按题确认，页面也按题分组展示。

## 2. 核心原则：三件套要咬合

三件套是：

- 驱动力：主角为什么往前走；
- 金手指：凭什么走得动；
- 核心循环：每个单元怎么走。

这三样必须是一套，互相咬合。

- **咬合的例子**（虚构）：
  - 驱动力：找回被人偷走的十年记忆；
  - 金手指：能读出旧物上残留的记忆；
  - 核心循环：接委托、读旧物、破案，每个案子都带回一块自己的记忆碎片。

  主角每破一案都离真相更近。读者每个单元既有破案的爽，也看着主线往前走。
- **脱节的例子**：驱动力是复仇，金手指是种田系统，核心循环是经营农场。主角天天种地，复仇只在开头和结尾出现，读者会觉得主线是摆设。

作者举的例子都是咬合的。驱动力这一项按作者的描述是：

- 云澈：为了身边的红颜不得不变强；
- 陈歌：寻找失踪的父母；
- 封不觉：找回自己的恐惧。

## 3. 新的开书步骤

| 步骤 | 这一步回答的核心问题 | 和现在比 |
|---|---|---|
| 选方向 | 这本书大概往哪个方向写 | 方向卡增加「驱动力」「核心循环」两行速写 |
| ① 定调 | 这本书是什么、写给谁、凭什么好看 | 新增核心循环；主角的内容移到② |
| ② 主角 | 他是谁、想要什么、为什么、凭什么、会怎么变 | **新增一块** |
| ③ 世界与对手 | 在哪里打、和谁打、藏着什么秘密 | 从「人物上轴」拆出来，提到节点之前 |
| ④ 关键节点 | 从开局怎么一步步走到结局 | 节点要写清主角的追求怎么变 |
| ⑤ 人物群像 | 还有谁、什么时候出现、和主角什么关系 | 原「人物上轴」剩下的部分 |
| ⑥ 填中间 | 节点之间分几卷、几条线怎么交织 | 基本不变 |
| ⑦ 第一卷 | 第一卷怎么拆成剧情单元 | 基本不变（开篇专项在后面的包里） |

每一步都可以点「交给编辑部定」直接过，所以步骤多了，并不等于作者要多花很多力气。

## 4. 每一步的必答题

### 选方向（入口）

方向卡在现有内容之外，增加两行：

- **驱动力**：主角为什么往前走，一句话。
- **核心循环**：主角每个单元在做什么，一句话。

选方向时作者看的是整本书的轮廓，这两行最能看出这个方向立不立得住。

### ① 定调：这本书是什么、写给谁、凭什么好看

| 必答题 | 合格标准 |
|---|---|
| 题材与读者 | 什么类型；男频还是女频；这类读者爱看什么、最讨厌什么（雷点） |
| 对标作品（作者提到才有） | 借鉴它的什么、哪些地方要不一样 |
| 一句话故事 | 50 字内：谁、想要什么、最大的阻碍、和别的书哪里不一样 |
| 核心卖点 | 2-3 个，具体到读者会为哪种场面叫好，不写「热血」「很爽」 |
| 核心循环 | 主角在一个个剧情单元里反复做的那件事，以及读者每个单元能拿到的爽感 |
| 基调与文风 | 轻松还是压抑、幽默还是冷峻；人称 |
| 篇幅 | 多少万字、每章多少字、大约多少章 |
| 书名 | 一眼看出卖点，念得顺、记得住 |

- 下游：后面每一步。
- 和现在比：主角钩子、金手指移到②；舞台阶梯移到③。

### ② 主角：他是谁、想要什么、为什么、凭什么、会怎么变

| 必答题 | 合格标准 |
|---|---|
| 起点 | 身份、开局处境有多低多难；读者为什么会代入他 |
| **驱动力** | 见下文 |
| 性格与底线 | 2-3 个核心性格加一个反差；做事的风格（杀伐果断还是留余地）；绝不做的事 |
| 金手指 | 一句话规则；成长路线（每个阶段解锁什么）；限制；谁知道；来历是不是一个谜 |
| 软肋与成长 | 最大的缺点或心结；从什么样的人变成什么样的人 |
| 在乎的人 | 哪几个人是他的情感锚点，这些人往往就是驱动力的来源 |
| 咬合检查 | 驱动力、金手指、核心循环是不是一套（第 2 节） |

驱动力是这一块最重要的题，分四层回答：

1. **开局动机**：开局发生了什么，逼他不得不行动。比如鬼屋要倒闭、被退婚、父母失踪。
2. **长线追求**：贯穿全书或大半本的追求，比如找人、复仇、守护、找回、证明、求生、登顶。
3. **情感根源**：他为什么在乎——爱谁、欠谁、怕什么、缺什么。没有情感根源的追求，读者不会跟着在乎。
4. **怎么升级**：舞台变大以后，追求怎么跟着变大；会不会在某个节点换成新的追求。可以换，但要在④的节点里写清在哪换、为什么换。

驱动力的合格标准：

- 要具体：写「找到失踪的父母」，不写「变强」。
- 要有情感根源。
- 不能全书只靠「变强」撑着。

下游：

- 关键节点：主线就是驱动力一步步展开。
- 人物群像：在乎的人要落成具体人物。
- 写作：设定师随定稿记下主角「此刻想要什么」，写手每章都拿到，主角的行动就有理由。

### ③ 世界与对手：在哪里打、和谁打、藏着什么秘密

| 必答题 | 合格标准 |
|---|---|
| 世界规则 | 力量体系（境界从低到高）或超自然规则；能做什么、不能做什么、代价是什么 |
| 舞台阶梯 | 每一层大地图的势力格局、强者上限、特殊规则；主角大约在每层待几卷 |
| 终极敌人 | 他想要什么；为什么必然和主角撞上；前期以什么方式露面（传说、阴影、代理人） |
| 对手阶梯 | 每层地图的主要对手，一个比一个强，各有目标和谋划 |
| 核心谜团 | 世界或主角身上最大的秘密；读者从什么时候开始好奇；分几次揭开。最好和驱动力挂钩，比如父母为什么失踪 |

下游：关键节点、人物群像、信息差表。

### ④ 关键节点：从开局怎么一步步走到结局

| 必答题 | 合格标准 |
|---|---|
| 核心矛盾与主题 | 主角想要的和挡着他的是什么；这本书最终想说什么 |
| 开篇与结局 | 开篇前 3 章抛出钩子；结局回应开篇，也回应驱动力（找到了没有、代价是什么） |
| 中间节点 | 发生什么、之前得先有、之后变成；**「之后变成」要写清主角的追求有没有变、变成什么** |
| 节点之间的路 | 每两个节点之间，主角靠核心循环怎么一步步走过去 |

节点里的驱动力要有回应：每隔几个节点，长线追求就要有实质进展，比如找到一条线索、离仇人更近、救下一个人，不能一直原地踏步。

### ⑤ 人物群像：还有谁、什么时候出现、和主角什么关系

| 必答题 | 合格标准 |
|---|---|
| 重要配角 | 女主、伙伴、导师、对手各自想要什么、性格、说话方式、和主角之间的张力 |
| 人物锚点 | 谁在哪个节点前后登场、确认关系、翻脸、退场 |
| 信息差 | 关键秘密谁知道、读者知不知道 |
| 感情线 | 单女主、多女主还是无感情线（按定调和作者的规矩），每段感情怎么开始、卡在哪 |

### ⑥ 填中间、⑦ 第一卷

和现在一样。增加两条检查：

- 每一卷都要写清主角这一卷想要什么，它和长线追求是什么关系；
- 每个剧情单元都要能看出核心循环在转。

## 5. 页面跟着改

- **按题分组**：每一步的页面按必答题分组，每道题一个小节，小节标题就是问题本身，例如「他为什么要往前走」。答得不合格的题，由程序检查或审稿标出来。
- **概念页现在的排版问题**：
  - 右栏把主角钩子、基调、舞台阶梯、目标读者、篇幅五样性质不同的东西竖着堆在一起，左栏只有卖点，两栏一长一短。
  - 舞台阶梯是「A → B → C」，却按普通段落折行。
  - 篇幅是程序算出来的灰字，和作者能改的内容混在一起。
  - 正在编辑的灰底和铅笔图标贴在栏边上。

  改成按题分组以后：读者、基调、篇幅这类短的事实，用「一行一项」的紧凑表；舞台阶梯画成一节节台阶，放到③；主角的内容整块移到②。
- **进度条**：从五块变成七块，窄屏仍然缩成一行。

## 6. 要作者拍板的问题

1. 七步会不会太多？要不要把③并进②，或者把⑥⑦合成一步？
2. 核心循环是不是每种书都要有？恐怖、悬疑、无限流很需要；以感情为主的书可以弱一些。
3. 主角的驱动力允许中途更换吗？建议允许，但要在节点里写清在哪换、为什么换。
4. 还有没有你觉得开书必须想清楚、但上面没列出来的？
