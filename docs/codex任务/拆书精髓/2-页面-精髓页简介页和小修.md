# 拆书精髓（任务 2 · 页面）：精髓页、拆的书的简介页、设定页几处小修、编辑部按钮

任务 1 做完、提交以后再做这个。要用任务 1 的接口 `GET /api/books/{id}/teardown/essence`、摘要里的 `teardown.essence`、拆的书角色的 `position`。

共同约定照本目录的 `README.md`（不再照装修那份），页面比对见那里第 12 条。

## 0. 复刻要求（最要紧，先读这一节）

作者对页面的感觉非常在意，原话是「不要失之毫厘差之千里，差一点整体的感觉就会差很多」。上一次新书页装修照样张做到了「一模一样」，作者很满意，这次照同一个标准做。

### 0.1 样张就是标准

样张有三份：

- `docs/界面原型/精髓样张.html`
- `docs/界面原型/精髓样张-数据.js`
- 截图 `docs/界面原型/精髓样张/v-*.png`，1600×900，用 `docs/界面原型/截精髓样张.mjs` 截的

页面上的每一样，都要和样张一模一样：

- 字（一个字、一个标点都不差）
- 字体、字号、字重、行高、字距
- 颜色、边框、圆角、阴影
- 间距、对齐、换行的位置
- 栏宽、图标、列表符号、编号的样子
- 屏幕大小变了以后怎么放大（照新书页现有的 fit：按 1700 宽排，最多放大 1.5 倍）

### 0.2 不要自己发挥

- 不要「顺手优化」；
- 不要「看着差不多」；
- 不要换成你觉得更好看的写法；
- 不要用别的组件凑出「像」的效果。

样张里的 CSS，除了装修样张原有的那部分，新加的是最后三块：精髓页和新简介页（`.kp`、`.figs`、`.intro2` 这些）、右栏数字条（`.bars`、`.feelstrip`）、编辑部按钮（`.ball`）。这三块照现在 `desk-v2.css` 的办法，机械地加 `.desk-v2` 前缀并进去，值一个都不改。

### 0.3 拿不准就问

样张没画到的地方（第 2.5、3.3 节写了的照写）：只能用现有页面已有的样子，不能新造。实在拿不准，停下来问，不要猜。

### 0.4 怎么证明一模一样

照装修那次的做法，用 `frontend/tests/desk-v2-parity.browser.mjs` 那一套逐页比对：

- **比哪些页**：简介，精髓的核心要点、情节怎么想、剧情骨架、剧情衔接、保持新鲜、长线布局、设定设计、爽点类型、爽点戏怎么写、主角、配角与对手、节奏与钩子、开篇，一共 14 页。
- **两种尺寸**：1600×900 和 2560×1312，一共 28 组。
- **同一份数据**：在《逆天邪神》的只读副本里，把 `精髓样张-数据.js` 的 `essence` 原样写进 `books.teardown["essence"]`（补上 `inputs: {}`、`failed: false`）。书名、作者、章数、读过的章数、单元数，副本里本来就和样张一样，核一遍。
- **三项都要过**：
  - 文字（innerText）完全一致；
  - 计算样式和装修那次一样比 38 项，长度容差 0.5 CSS px，未解释差异为 0；
  - 像素差（pixelmatch threshold=0.1，整张图作分母）每组 ≤0.5%。
- **会变的东西**：存档的「几分钟前存过」照装修那次固定浏览器时钟；不许为了过比对去遮东西、放宽阈值、改样张。
- **差异照实写**：每组的差异、原因写进验收说明。

## 1. 精髓页

### 1.1 入口

- 拆的书的顶栏标签变成「简介 · 精髓 · 设定 · 大纲 · 正文」，精髓在简介后面。作者自己的书不加。
- 切到精髓，默认打开「核心要点」；记住上次看的那一节，和别的标签一样。

### 1.2 左栏目录（样张 `tocEssence()`）

- 最上面是搜索框「找知识点……」。
- 然后是：
  - 「核心要点」一行（`row top1`），右边是条数；
  - 五组，每组一行 `row unit`，下面 `kids` 里是这一组的各节，右边是条数。
- 组和节：

  | 组 | 节 |
  |---|---|
  | 剧情（后面一个 `chip seal`「重点」） | 情节怎么想、剧情骨架、剧情衔接、保持新鲜、长线布局 |
  | 设定 | 设定设计 |
  | 爽点 | 爽点类型、爽点戏怎么写 |
  | 人物 | 主角、配角与对手 |
  | 节奏与开篇 | 节奏与钩子、开篇 |

- 接口没返回的节不显示；一组的节都没有，这一组也不显示。
- 条数：知识点条数，配角与对手再加上人物数。
- 搜索：输入后，只留下 title、steps、evidence、note 或者人物（名字、人设、怎么立、作用、变化）里含这几个字的节，右边的数字换成这一节里命中的条数；核心要点照同样的规矩。清空恢复。
- 最下面「存档」那一栏和别的标签一样。

### 1.3 中间一节一页（样张 `essencePage()`）

**每一节**：

- 上面：`kicker`「精髓 · {组}」、`h1` 节名、`meta`「{这一节的一句说明} · 基于前 {upto} 章」、`rule1`。每节的那句说明照样张 `LEADS`。
- 每条知识点：
  - 标题：序号、招式名（红色）、冒号、后半句；
  - 「怎么用」：一步一行，前面圆圈编号；
  - 「这本书里」一行；
  - 「注意」一行（没有就不出）。
- 正文里的「第 N 章」「第 a–b 章」照样张的 `.ref` 样子显示，点了打开那一章（和大纲里点章一样跳到那一章的页面）。
- 有 `missing` 的，最下面一行 `.state`「还看不出来：…」，几条用「；」接。

**配角与对手**：先是「重要人物 N 个」的卡片（两列），然后小标题「人设怎么搭、怎么立」，下面是知识点。

**核心要点**：

- 上面 `kicker` 只写「精髓」；
- meta 是「如果只学几件事，先学这几件 · 基于前 {upto} 章」；
- `rule1` 下面先一行 genre（小字），再一段 engine（大字），然后是知识点。

### 1.4 右栏（样张 `RAIL`）

| 哪一节 | 右栏放什么 |
|---|---|
| 核心要点 | 「这本书的数字」＋「各类爽点出现几章」（前 6） |
| 情节怎么想 | 「每个单元的事从哪来」＋「单元」列表 |
| 剧情骨架 | 「单元」列表 |
| 剧情衔接 | 「读者在等的事」＋「单元」列表 |
| 保持新鲜 | 「赌注比上一单元」 |
| 设定设计 | 「拆出来的设定」 |
| 爽点类型 | 「各类爽点出现几章」＋「靠旁观者放大」 |
| 主角 | 「出场最多的人」 |
| 配角与对手 | 「出场最多的人」＋「并成同一个人的」（没有合并就不出） |
| 节奏与钩子 | 「逐章的读者感觉」色条＋「章末钩子」 |
| 长线布局、爽点戏怎么写、开篇 | 没有内容，右栏空着占位，照样张 |

数字都从 `essence.rails` 来，不另算。

### 1.5 没有精髓、正在整理时

（样张没画，照现有 `.state` 的样子，放在 `rule1` 下面）

- **接口返回 `null`**，只出一页：`kicker`「精髓」、`h1`「核心要点」、`rule1`，下面一行 `.state`：
  - 一章都没读：「还没开拆。拆过的章会整理成一条条知识点：情节怎么想、设定怎么设、爽点怎么造、人物怎么立。」
  - 正在拆：「拆书收尾时整理精髓，到时这里就有了。」
  - 拆完了（stage 是 done）：「还没整理精髓：点右上角「补上整理」，不重读原文。」
  - 其余：「还没整理精髓：点右上角「接着拆」，选「只整理前 {last_read} 章」，不重读原文。」
- **有精髓、但正在整理新的**：照旧显示现有的，不加提示（顶栏进度那行字会说，见 1.6）。

### 1.6 顶栏进度那行字（`teardownProgress.ts`）

- `essence`：「主编在整理精髓：{now}」。
- 「开始拆」对话框全书都读过时那段话，改成：「全书 {total} 章都读过了。这次不重读原文，只把收尾补上：没归完的单元和卷、篇、全书结局、设定、读者在等的事、精髓，做好了的不重做。」

## 2. 拆的书的简介页（样张 `intro()`）

### 2.1 整体

整页照样张：`page full` 里左宽右窄两栏（`.intro2`）。作者自己的书的简介页一点不动。

### 2.2 左栏，从上往下

1. **书**：封面、`kicker`「拆的书」、书名、`meta`「原书作者 {author} · {chapters} 章」（作者空写「（文件里没写）」）、`statline` 三个 chip，然后：
   - 「已拆 {read} / {chapters} 章」
   - 「{units} 个单元」
   - 「精髓基于前 {upto} 章」（没有精髓不出）

   下面一行 genre 小字（没有精髓不出），再下面「补后面的章节」按钮（现有的那个，规矩不变）。
2. **一句话看懂**：label 右边「去精髓页 ›」点了打开精髓的核心要点；下面 `lead` 是 engine。没有精髓不出这一块。
3. **最值得学的几件事**：label 右边「全部知识点 ›」同上。下面编号列表，取核心要点前 4 条：粗字是 title，小字是 steps 去掉末尾标点、用「 → 」接起来。点一条打开核心要点。没有精髓不出。
4. **故事走到哪了**：
   - label 右边「一格一个单元」；

   - 点卡片打开大纲里那个单元。

5. **原书简介**：`intro` 有才出，`lead` 小一号、保留换行。

### 2.3 右栏，从上往下

1. **主要人物**：label 右边「主角在前，其余按出场」。
   - 列 `rails.people` 前 7 人：名字；主角后面红 chip「主角」，其余有人设的（配角与对手那一节里的 archetype）后面黄 chip；右边「{n} 章」。
   - 点名字打开设定里那张卡。
   - 没有精髓：按角色 `position` 列前 7 人，不带 chip，不写章数。
2. **读者爽在哪**：label 右边「各类出现几章」，`rails.tags` 前 6 条数字条。没有精髓不出。

4. **已拆部分的节奏**：label 右边「逐章的读者感觉」，色条和下面一行说明照样张。没有精髓不出。

## 3. 设定页几处小修

### 3.1 目录点了能收起

现在设定目录的「展开」是跟着选中的条目走的，点不收。改成：

- 点一个没展开的分类：展开，并打开这个分类的页（和现在一样）；
- 点一个已经展开、并且正选中着的分类：收起（页不换）；
- 点前面的小箭头：只展开或收起，不跳页。

大纲目录的卷、单元照同一个规矩改，作者自己的书和拆的书都一样。

### 3.2 角色顺序

- 拆的书：角色列表和简介页（没有精髓时）都按 `position` 排（任务 1 已经写好：主角 0，其余按出场）。
- 作者自己的书：置顶的在前（现有规矩），然后定位是「主角」的，然后照现有顺序。

### 3.3 只记一句话的人（拆的书）

只出场两到四章、没有名场面的人，任务 1 之前就只写一句话（`one_line`），但卡片页没显示，右栏还写「记录里没有：所属、性别……」，作者以为是 AI 偷懒。改成：

- 卡片页 `meta` 下面，用 `lead` 显示这句话（和角色卡其他正文同一个样子）；
- 右栏「记录里没有」那一块，对这种人换成一个 `rb`：标题「只记一句话」，正文 `.small`「出场 {n} 章。出场 5 章以上或者有名场面的人才写全卡，其余的只记一句话。」

判断「只记一句话」：卡上除了名字、别名、定位、一句话以外，别的栏都空。

### 3.4 拆的书角色卡的「成长与结局」

拆的书的卡上这一栏的标题显示「变化」，右栏「记录里没有」列到这一栏时也写「变化」（装修样张的茉莉卡已经这样改了）。字段不变，作者自己的书不变。

## 4. 编辑部按钮（所有书）

**样子**：照样张的 `.ball`，朱砂印章：

- 红底、米白色「编」字；
- 圆角 10px，里面一圈细的米白边；
- `hover` 颜色深一点。

**拖动**，照样张最后那段代码：

- 按住移动超过 4px 才算拖；拖的时候加 `.dragging`；
- 松手贴到最近的左边或右边，离边 24px；上下照松手的位置，离顶栏和底边至少 16px；
- 位置记在 localStorage `zhibi.ball`，`{side, top}`，`top` 是比例；读不出来就用默认位置（右下）；
- 窗口大小变了重新摆；
- 没拖、只是点一下，才打开编辑部，和现在一样；拖完松手不打开。
- 整页放大（fit 的 zoom）时位置要算对，样张里有换算。
