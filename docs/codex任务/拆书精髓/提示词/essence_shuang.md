【这一节：爽点类型】
讲清楚这本书让读者过瘾的是哪几类爽点，每一类这本书通常怎么造出来。每一类一条，不复述剧情。

{{materials}}

要求：
1. 上面数好的各类里，占过瘾章数一成以上的类，每类写一条（最多 7 条，按出现章数排）：
   - title：「类名：这本书里这一类的样子」，类名就用上面的类名；
   - steps：造这一类爽点的步骤（先压什么或蓄什么 → 在哪一下给出来 → 靠谁的反应放大 → 主角最后拿到什么）；
   - evidence：出现几章、大爽几次、大概隔多久来一次，再举两三个例子。
2. 如果这本书总是把几类叠在一起用、或者总靠旁观者的反应把爽放大，用最后一条讲这个叠法（不占上面的名额）。
3. 憋屈怎么安排不在这一节写。
