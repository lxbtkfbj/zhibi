# 开书

什么时候翻：作者问到怎么开一本新书，或者想定、想改一本书的世界观、主角、金手指、核心循环这些根基。

## 四块基石

开一本书，先要立住四样：世界观、主角驱动力、金手指、核心循环。它们各管一件事，又互相咬着。

常说的套路，就是这四块合起来的样子，名字取自其中最显眼的一块：退婚流、废柴流说的是主角的处境，系统流、老爷爷流说的是金手指，无限流、经营流说的是核心循环，灵异复苏、末世说的是世界观。

## 一、世界观

管的是这个世界和别的书不一样的那根骨头。包括：

- 力量或危险从哪来，按什么规矩运转，用它要付什么代价。
- 舞台怎么铺开：一块大陆往外走，一层层往上升，现实加副本，现实背面藏着另一个世界……
- 谁说了算，主角在哪一层。
- 深处藏着什么：一段历史、一个秘密，往往就是全书的底。
- 这个世界给读者的味道。

同类书的骨头可以完全不同：

- 斗破苍穹是一块大陆往外走，从乌坦城一路走到中州。力量是一条清楚的梯子，从斗者到斗帝。炼药师和异火是这个世界的特产，也是萧炎的金手指长出来的土壤。看点是往上爬。
- 逆天邪神是一层套一层，从天玄大陆一路往上走到神界，头顶还压着一段远古神魔的历史，云澈身上的邪神玄脉就来自那段历史。看点除了往上爬，还有一层层揭开历史。
- 惊悚乐园把恐怖放进游戏的一个个剧本里，剧本五花八门，不只有恐怖。看点是主角怎么用脑子破局。
- 恐怖复苏让恐怖闯进现实，无处可逃。鬼按自己的规律杀人，杀不死，只能压住；人只能借鬼的力量，用得越多，离被鬼反噬越近。味道压抑，看点是求生和摸清规律。
- 我有一座恐怖屋的城市表面正常，背面藏着灵异事件。主角守着一座鬼屋，一次次闯进灵异事件里，把鬼收成员工，把鬼屋做大。味道是悬疑里带着温情。

同样是恐怖，差在四处：危险在哪儿，主角有没有安全的地方，力量从哪来、要付什么，是什么味道。世界观一变，整本书的看点和循环都跟着变。

好坏的分水岭：

- 新意要落在规矩上，换名词不算。把灵气改个叫法不算新，力量的来路、规矩和代价跟别人不一样才算。
- 世界观要能生出冲突、撑起循环。地图、副本、灵异事件，本身就是一圈圈故事的舞台。
- 只做故事用得到的，读者需要时再放出来；开篇不铺大段设定。

## 二、主角驱动力

管的是他为什么动、怎么动、往哪动。包括：

- 人设：性子、行事风格、底线、让人记得住的地方。
- 处境：开局在哪，被什么压着，为什么必须现在动。
- 目标：眼前非做不可的，和长远想要的。他想要什么，就有谁不让他得到。

处境逼他动，人设决定他怎么动，目标决定他往哪走。常见的驱动有求生、雪耻复仇、守护、找人或求真相、兴趣和欲望、改命。

- 萧炎：天才跌成废柴，又被人上门退婚，于是立下三年之约。
- 云澈：睚眦必报、极度护短，一心要回流云城向萧门复仇，接回爷爷和小姑妈。
- 杨间：被鬼盯上，先得活下去。
- 陈歌：守着父母留下、快要倒闭的恐怖屋。眼前要把鬼屋做起来，长远要找到失踪的父母。
- 封不觉：没有恐惧的推理小说家，进惊悚乐园是为了找回恐惧。

好坏的分水岭：

- 主角要主动：从他想要的出发，靠自己的选择推动故事，而不是被剧情推着走。
- 人设要落到行动上。同一个困境，换个性子就是另一种破法；读者追的，就是这个人接下来会怎么做。
- 眼前的目标要足够急，长远的目标要足够大。
- 最常见的毛病：没性子，换谁来都一样；没有自己想要的东西。

## 三、金手指

管的是他凭什么。

金手指是能带来优势，而且别人没有、只属于他的东西。拼命能拿到、别人也拿得到的，不算。杨间的鬼怪能力都是拼死抢来的，别人也能抢；他身上最像金手指的，只有那张人皮纸：会在关键时刻透露消息，消息还掺毒。

不是每本书都要金手指。没有金手指的书，读者看的是主角怎么凭自己拼出来。

有金手指，要想清楚四样：

- 能力：能干什么，怎么一路变强。
- 限制和代价：用一次要付什么，有什么做不到。
- 来历：从哪来，为什么偏偏落在他身上。
- 背后真相：往往连着世界的秘密和全书的底。

几个例子：

- 萧炎戒指里住着药老。他当了三年废柴，正是因为药老在吸他的斗气，所以金手指一出场，就和他的处境是同一件事。药老传给他的功法能吞异火进化，成长的路一眼看得见。
- 封不觉没有恐惧，这在恐怖游戏里是天大的优势。他玩游戏是为了找回恐惧，而他的恐惧是被伍迪封印的。金手指、驱动、真相，是同一件事。
- 陈歌的黑色手机是在父母失踪的现场找到的，只有他能开机，手机上的任务一步步把鬼屋做大。金手指的来历，直接连着全书最大的谜。

好坏的分水岭：

- 有代价才有悬念。没上限、没代价，主角怎么打都赢，读者就不紧张了。代价也可以放在世界的规矩里，恐怖复苏的驭鬼就是这样。
- 有成长的路，读者才有盼头。
- 要和世界观是同一套规矩，不能违和。
- 来历里要留着真相，后面才圆得上。
- 三句话说不清的金手指，读者记不住。

## 四、核心循环

管的是长篇靠什么一直好看：每一段故事里，主角都在反复做的那件事。

- 斗破：换一张地图，被人压着，夺到机缘，当众打脸，升级，再被引向更大的地图。
- 恐怖复苏：出一桩灵异事件，摸清鬼的规律，驭鬼压住它，付出代价，接着是更大的事件。
- 恐怖屋：接试炼任务，闯进灵异现场，化解或收服厉鬼，鬼屋升级、员工变多，离父母失踪的真相又近一步。
- 惊悚乐园：进一个剧本，用脑子破局，拿到奖励，再进下一个。剧本类型一直在换。
- 换到别的题材也一样：言情是一次次的感情推进和拉扯，宫斗是一轮轮的算计和反击，推理是一个个案子。

循环定了，套路也就定了：读者就是冲着循环里那种满足来的。

好坏的分水岭：

- 每一圈都兑现读者冲着来的那种满足。
- 一圈比一圈大：对手、舞台、赌注都在升级。
- 每一圈都有变化：舞台、对手、破法都要换，不能重样。
- 每一圈都带着长远目标往前走一步，不然就成了流水账。
- 开书时想一想：十圈以后，它还转得动吗？

## 四块怎么咬在一起

- 金手指和世界观是同一套规矩：斗破的炼药师和异火，就是萧炎的金手指长出来的土壤。
- 处境加上金手指，就是开局：处境把他逼到墙角，金手指第一次亮出来，第一圈循环开始转。
- 人设决定他在循环里怎么破局。同样是闯副本，封不觉靠的是脑子和不按常理出牌，换个人就是另一本书。
- 远处那一头要拧成一股：主角的长远目标、金手指的真相、世界深处的秘密，在好书里常常是同一件事。拧成了，就是贯穿全书的主线；拧不上，书写到后面就会散。
- 味道要统一：世界、主角、循环，得是一个味道。
- 四块里最跟别人不一样的那一下，压成一句话，就是这本书的卖点。

## 开书时定到什么程度

近处要清楚，远处一句话就够：

- 世界观：开局那片世界要清楚，远处和深处的秘密一句话。
- 主角驱动力：人设、处境、眼前目标要清楚，长远目标一句话。
- 金手指：能力和限制要清楚，来历和真相一句话。
- 核心循环：要清楚，而且能转很多圈。

模糊不等于空白：远处那一句话开书时就要有，前面才好埋伏笔。几十万字的世界开书时就想全，反而会乱。

感情线和班底看题材：如果它们就是这本书的核心，开书就要定。言情里，感情线本身就是循环；恐怖屋里，收鬼当员工就是每一圈的收获。
