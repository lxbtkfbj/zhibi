# 小修 4：编辑部贴到右边时，聊长了输入框就没了

## 现象

作者在《佔位》（`413c96ac-…`）里和主编聊了一大段，编辑部贴到右边（侧栏）时，底下的输入框看不见了，聊天记录也上下滚不动。浮窗模式是好的。

## 设计方复现和原因

在作者的 4320 上，窗口 1280×800、设定页、编辑部贴右边：

- 书桌主体 `.desk-v2 .body` 是网格，高 746px，只有一行，没写 `grid-template-rows`，这一行按格子里的内容定高。
- 右栏 `aside[data-testid="editorial-docked"]`（`frontend/src/pages/workspace/Workspace.tsx` 约第 541 行）是网格的一格，`min-height` 是默认的 `auto`，于是按整段聊天的高度把这一行撑到了 2435.5px。左边目录和中间的页面都有 `min-height: 0`，不受影响。
- 外层 `.desk-v2` 是 `overflow: hidden`，所以输入框（在 y=2369）被藏在屏幕外；聊天列表（`overflow-y-auto`）自己有 2244px 高，内容也是 2244px，不出滚动条。
- 设计方在页面上临时给右栏加 `min-height: 0` 试过：右栏变回 746px，输入框回到 y=679，聊天列表可见 554px、内容 2244px，能滚。

这块从「新书页装修」（`0a41e27`）起就没动过，聊天长过一屏才露出来。

## 0. 共同约定

照 `2-小修.md` 第 0 节（只照那一节），只有这几处不同：

- 只改前端。`desk-v2.css` 不能改，要加样式放 `frontend/src/styles/desk-v2-host.css`，或者直接在右栏的 class 上改。
- 不改后端，后端全量照跑（确认没碰坏）；不跑真文件复核。
- 验收接在 `docs/拆书导入验收.md` 后面写一节「小修 4」，截图文件名以「小修4-」开头，一张就够。

## 1. 要改的

1. 编辑部贴右边时，右栏的高度永远等于书桌主体的高度，不被聊天内容撑高：输入框一直在右栏最下面看得见，聊天记录在中间自己滚动。
2. 顺手查一遍书桌右边别的会贴住的栏（比如「待处理」、存档那一栏，凡是放进 `.desk-v2 .body` 网格的），有同样毛病的一起这样改，列进验收说明；没有就写「没有」。
3. 浮窗、收成小球、拖分隔线改宽度，样子和用法都不变。

## 2. 测试

浏览器测试，用一本聊天很长（消息加起来远高于一屏）的书：

1. 编辑部贴右边，窗口 1280×800 和 1700×900 各一次：右栏高度等于书桌主体高度；输入框整个在窗口里；聊天列表能滚到最上面和最下面；在输入框里打字、点发送这些都能用真鼠标点到。
2. 写的书简介、设定、大纲、正文四页，拆的书再加精髓页，都各试一次（简介页的网格列和别的页不一样）。
3. 切回浮窗：照旧能拖、能点「以前的对话」。

精髓 28 组、装修 16 组比对照样全过，不加遮挡、不放宽阈值。
