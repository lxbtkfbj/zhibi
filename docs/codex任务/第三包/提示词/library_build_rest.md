要求：
1. 用得上的才建。每一条先问三个问题：是不是这本书的卖点？第一卷的正文会不会碰到？以后改了，前面写过的会不会变成错的？
   - 是卖点或第一卷天天用的，写「现在要定」，写出一段话；
   - 有现成惯例的（修仙用灵石、现代照现实），写「一句话就好」；
   - 后面才用到的，写「以后再说」，只留名字和一句话；
   - 照现实就行、用不上的，不建。
2. 【设定库里已经有的】是作者写好或认可的：这些条目和人物不要重写、不要换名字，也不要再建一条差不多的；围着它们补缺，新建的要和它们对得上。
3. 世界与地图的第一条叫「世界概况」（已经有了就不再建）：什么时代、超凡是公开的还是藏着的、钱用什么、社会风气。之后只细写第一卷的舞台；后面的地方，定调里提到了才列名字，写「以后再说」，不要硬排。
4. 等级体系写总说明和各级（从低到高）：前几级写介绍，高阶的可以只写名字。这本书没有正式的等级，就写一级「没有」，在总说明里说清怎么看强弱。
5. 人物：第一卷就登场的写全（班底、女主或男主、导师、开篇的小麻烦、第一个大对手），每个人写清想要什么、和主角的关系、性格里的反差；后面才登场的写「以后再说」。要紧的人物八个以内（含已经有的），人名好记、不撞车。
6. 每一条都要和定调、底牌、主角、金手指对得上；地方里提到的境界，要用等级体系里的叫法。
7. 熟悉的爽点写到位，再加一两处新意；对手要有自己的目标，不能是专门来欺负主角的。
8. 七个默认类别放不下、又是这本书的核心东西（比如灵异书里一只只厉鬼、无限流里一个个副本），才建议新建自建类别；属于它的条目照样写在 entries 里，类别写这个自建类别的名字。
9. 列出你替作者做的、作者可能想换的关键决定，最多 3 个。
