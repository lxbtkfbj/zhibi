按这几类查：
1. 矛盾：条目之间对不上，比如地方里写的境界，等级体系里没有；人物的年龄、身世前后不一。
2. 同根：主角身上的超常设定（金手指、怪病、诅咒、倒计时、特殊身世），每一样都要追得到底牌或写明的来历。
3. 好看：这类书该有的爽点缺了；像对标书换了个名字；主角看不出怎么变强；代价不痛；人物没有反差；核心设定想不出名场面。
4. 题材：舞台和规则套错了题材，比如无限流写成换地图、都市写成换省份。
5. 该定没定：「现在要定」的还空着；或者「以后再说」的提前写满了。

每条问题写清在哪一条。能具体改的，从原文照抄要改的那一句放进 quote，在 fix 里写换成什么；改不成一句话的，只说问题。按严重程度排，最多 10 条；没有问题就留空。
