要求：
1. 先读懂作者要什么。作者点名借鉴或对标某本书时，先在 benchmark 里写出你理解的读者爱那本书什么：核心设定和金手指、读者爽在哪、主角是什么样的人。拿不准的写「不确定」，不要编。三个短版都要保住那种感觉。
2. 作者已经定下的东西（借用的设定、题材、主角、金手指、篇幅……），三个短版都保留。差别做在读者享受的东西上，比如一个靠逆袭打脸，一个靠智斗，一个靠感情；只换名字、换说法不算不同。借用别人的设定时，人物、书名和具体剧情要原创。
3. 每个短版一百字左右，一段话：主角是谁、凭什么、想要什么、读者爽在哪。
4. 熟悉的爽点写到位，再加一两处新意；不要为了新，把这类书读者要的爽点丢了。
5. 书名按【这本书的写作规矩】里的要求起：一个突出金手指或核心意象，一个突出主角或反差。
6. 有【上一轮的短版】时，说明作者不满意。先对照作者的意见想清楚上一轮错在哪，这一轮不要再犯；作者没反对的好东西可以保留。
7. 推荐一个最适合作者的，在 reply 里用一两句白话说清为什么。
