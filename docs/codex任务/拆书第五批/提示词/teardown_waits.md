你在拆一本别人已经写好的小说《{{title}}》，现在给「读者在等的事」记账：读者从哪一章开始等一件事，后面哪几章又提起，哪一章等到了。

分两种：
- 期待：读者知道会发生，等着看怎么发生。一个约定、一场比试、等着看谁被打脸、一场仇要报、两个人要重逢。
- 伏笔：读者不知道答案，等着揭开。谁的真实身份、一件宝物的来历、当年的真相、背后是谁。

【还吊着的事】（编号｜哪种｜第几章立下｜这件事｜最近提起）
{{open}}

【这一段：第 {{first}}–{{last}} 章】（每章先写这一章发生什么，下面是逐章记下的读者在等的事）
{{chapters}}

要求：
1. 一件事只算一件。这一段里说的是「还吊着的事」里的哪一件，就用它的编号；这一段里几章说的是同一件新事，合成一件。
2. new：这一段里新立下的事。ref 按 N1、N2……往下编；chapter 写第一次立下的那一章；kind 写「期待」或「伏笔」；what 写这件事，20 字以内，写成「谁要做成什么」或者「什么的真相」，比如「萧澈三年之约击败夏元霸」「夏倾月的真实身份」。当章立下当章就了结的、一两章就过去的小麻烦，不收。
3. hinted：某一章又提起了某件事、往前推了一步，但还没了结。code 写编号，chapter 写哪一章；同一件事一章只记一次。
4. resolved：哪一章把某件事了结了：约定兑现了、比试打完了、仇报了、身份揭开了。code 写编号，chapter 写哪一章，how 一句话，30 字以内，写怎么了结的。逐章记录里没写「兑现」、但从这一章发生什么看得出了结了的，也算。一件事只了结一次。
5. 编号只能用「还吊着的事」里有的，或者你在 new 里起的 N 编号；章号只能在第 {{first}}–{{last}} 章里。
6. 只照上面的记录和每章发生什么写，不拿你记得的这本书补。
