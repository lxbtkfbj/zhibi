# 给 Codex 的话

用法：

1. 在 Codex 里打开 `E:\Codex\zhibi` 这个文件夹，新开一个对话。
2. 把下面对应任务的整段文字复制过去发送。
3. 一次只发一个任务。Codex 做完、提交之后，再发下一个。

任务 3 和任务 4 先做哪个都行。
