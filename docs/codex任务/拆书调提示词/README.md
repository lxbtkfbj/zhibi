## 已经拆好的书怎么重跑

读原文的改动只管以后新导入的书。整本重读太贵，不建议。

下面这几步只用已经记下的逐章记录，不重读原文：

| 顺序 | 命令（在 backend 目录） | 改的是什么 | 预计调用 |
|---|---|---|---|
| 1 | `uv run python scripts/teardown_rerun.py waits --book <书 id>` | 读者在等的事重新记账 | 冒险屋 16、惊悚乐园 19、逆天邪神 28 次 |
| 2 | `uv run python scripts/teardown_rerun.py settings --book <书 id>` | 金手指、等级、秘密这些设定重新整理，别称过滤。不加 `--force`：角色卡的记录没变就不重写，只有设定那几类重新调用 | 每本大约二三十次，看设定有多少样 |
| 3 | `uv run python scripts/teardown_rerun.py essence --book <书 id> --force` | 精髓整节重写，带核对 | 每本十几次 |

- 第 2 步要排在第 1 步后面：秘密要照读者在等的事里的伏笔对揭开章。
- 第 3 步要加 `--force`：`persona_essence` 是系统提示词，不算在「输入没变就不调」的比对里，不加就有几节不会重写。
- 每一步开头会先打印预计调用多少次，输入「继续」才开始。
- 跑完自动存一档「重跑：…」，不满意能回到上一档。
- 拆书精髓里的「爽点分类」「逐单元拆剧情」（tags、unitplot）这次没改，不用重跑。
- 合并同一个人（merge）的提示词这次也没改，同样不用重跑。
- 《逆天邪神》里「老者」那种把几个人并成一个的，要重读原文才能拆开；别称过滤会先把挂错的「蛰爷」这种去掉。
