# 聊天改进 任务 5：聊天框收拾好看

共同约定照本目录的 `README.md`。以前端为主；第 4 节要在作者的那条消息里多存一样东西，后端只加字段、不改行为。

## 为什么做

作者说编辑部的聊天界面不好看，最明显的两处：自己发的话没有气泡框；「修改」「复制」在自己那句话的左边，不在右下角。查过原因：

- 气泡其实在，只是看不出来：新书页装修（0a41e27）把聊天区的底色换成了 `--color-pane-mid: #e8dfcf`（`frontend/src/styles/desk-v2-host.css`），作者气泡还是装修前配旧底色的 `--color-author-bubble: #e7dece`（`frontend/src/index.css`），两个颜色几乎一样。
- `Chat.tsx` 的 `AuthorBubble` 把这两个按钮和气泡排在同一行，放在气泡前面。

另外几处一起收拾（第 3、4 节）。

## 1. 聊天区底色

- 新书页里聊天区的底色改成 `#f3ece0`，和左边目录栏同一个颜色：在 `desk-v2-host.css` 里换掉 `--color-pane-mid` 就行，`bg-pane-mid` 只有聊天区在用。
- 作者气泡照旧用 `--color-author-bubble`（#e7dece），编辑部的回答气泡照旧是白的。这样三样分得开：底色浅米色，作者气泡深一点的米色，回答白色。
- 深色模式（`desk-v2-dark.css`）的颜色不动，截图确认作者气泡看得见。
- 我在作者的书上临时换过这个底色看效果：作者气泡、白色回答都清楚。

## 2. 作者那句话的「复制」「修改」挪到右下角

- 挪到气泡下面，靠右，和气泡右边对齐。先「复制」后「修改」，和回答下面「复制」「重新回答」的顺序一样。
- 照旧是鼠标移到这句话上才出现，键盘 Tab 到也出现。出现、消失时，下面的聊天不跳动。
- 气泡不再给按钮让位置，最宽照旧是这一栏的 85%。
- 点「修改」以后的原地修改，还有「这句和后面的话改过书」那个提醒框，行为和字都不变；提醒框照旧在这句话下面。

## 3. 编辑部回答下面那几行

现在一条回答下面最多有三样，各占一行：「查了：……」、记忆那几行（记住了、改了一条记忆、忘掉了……，带撤销）、「复制」「重新回答」。改成：

- 「查了：……」和「复制」「重新回答」并成一行：「查了」在前，按钮在后；「查了」太长就截断（现在就是截断）。点开「查了」，查到的原文照旧在这一行下面展开。
- 不是最新一条的回答，按钮照旧鼠标移上去才出现；「查了」照旧一直显示。
- 记忆那几行（`MemoryNotice`）放进一个浅色小框，和「查了」点开后的框一个样子：圆角、细边、浅底，不加图标。每条记忆的字、撤销、灰掉时的样子和说明都不变。
  - 在回答下面：框在气泡和按钮那一行中间。
  - 作者那句话下面也会出记忆那几行（模型不能调工具时走这条路），一样放进小框。
- 小框和按钮那一行的左边，照旧和回答气泡对齐。

## 4. 看稿、开书时作者点的按钮和写的话，也用作者气泡

编辑部干活时，作者在看稿、开书那几步点的按钮、写的话，现在在聊天里是居中的一行灰色小字「你：……」（`LiveChat.tsx` 里 `job_id` 那一段的 ``你：${m.content}``），这也是「没有气泡」。改成：

- 和作者在聊天框里说的话一样：放在右边，用作者气泡，去掉「你：」。
- 只有「复制」，没有「修改」：这些是拍板，不能从这里重来。
- 点确认时顺手写的几句，现在聊天里看不到：消息里只有「确认「定调」。」「批准这一卷的卷纲，开写。」这种固定的话。
  - 写了的，放在同一个气泡里，固定那句下面另起一行。
  - 作者写的原话要存进这条消息。任务 4 加的 `payload.feedback_memory.feedback` 有的路径有、有的没有，所以统一在 `api/jobs.py` 的 `_queue_setup_response` 里把作者写的话存一份。只在写了、而且消息里没有这句话时存；只加字段，不改别的行为。
  - 以前的消息没存这一份，就只显示固定那句。
  - 让编辑部改的那种，消息本身就是作者写的话，不重复显示。
- 照旧不变的：
  - 紧跟着、复述作者决定的系统那句，照旧不显示；
  - 「【和作者商量定的方案」那种，照旧用方案的样子；
  - 编辑部干活时的别的小字（做完了什么 · 去看、等你看），照旧是居中的一行小字。

## 5. 不做

- 界面上的字不改，只去掉「你：」。
- 回答气泡、头像和名字那一行、输入框、浮窗和贴右边时的标题栏都不改。
- 旧版书页的 `MeetingFeed.tsx` 不改。

## 6. 测试

1. **前端**
   - 浅色、深色下，作者气泡和聊天区底色都不一样：取计算后的颜色来比。
   - 作者那句话的两个按钮在气泡下面，右边和气泡对齐；鼠标移上去才出现；出现、消失时，下面消息的位置不变。
   - 回答下面，「查了」和按钮在同一行；记忆小框在气泡和按钮行中间。
   - 看稿拍板显示成作者气泡，没有「修改」；写了几句的，显示在同一个气泡里。
2. **后端**：作者确认、批准时写的话存进了那条消息（只加字段）；别的行为不变，相关测试照旧过。
3. **浏览器测试**（演示模型，真鼠标、真键盘）
   - 发一句话：气泡看得见；鼠标移上去，右下角出「复制」「修改」；点「修改」，原地改了重发，照旧好用。
   - 一条查了资料、记了一条记忆的回答：「查了」和按钮在一行，记忆在小框里，能撤销。
   - 看卷纲时写一句再点「就这样，开写」：聊天右边出作者气泡，固定那句下面是写的话。
   - 浮窗、贴右边各看一遍。
4. **页面比对**：精髓 28 组、装修 16 组照跑。
