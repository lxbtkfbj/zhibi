## 任务 1：聊天框补齐

工作区干净就能发。

```text
请做执笔的「聊天改进 任务 1：聊天框补齐」，任务在 docs/codex任务/聊天改进/1-聊天框补齐.md，共同约定照同目录的 README.md。

作者嫌编辑部聊天框太简陋。要做五件，基本都在前端（Chat.tsx、LiveChat.tsx、lib/chat.ts、ChatActions.tsx），后台只改一句话：
1. 复制：作者的话、编辑部的回答都能一键复制纯文字。
2. 修改：「从这里重来」改名「修改」，改成在气泡原地改，取消、发送都在原地；发送照旧走 rewind 那条路，后台不动。
3. 草稿不丢：底下输入框没发的字和点了谁，每本书存在浏览器里，收起、换浮窗侧栏、换页、刷新都还在。
4. 回到最新：往上翻着的时候来了新回答，出「↓ 有新回答」，点了回到底部。
5. 回答下面的小字：去掉「只是聊天，没有记 · 其实要记下」，手动「记下」的按钮一律去掉（以后由编辑部自己判断、存进记忆，那是任务 2，这次不做）；另外三句照表改清楚，写作要求那边一律说「加了一条写作要求」，「记」字留给以后的记忆。

界面上的字逐字照任务文件。不改提示词，不碰日常 8000／4320 服务、worker 和书库，不调真实模型。小事按 README 第 5 条自己定、做完列出来；改提示词、动任务写死的东西、放宽或删测试才停下来问。提交前跑一次全量，两套页面比对照跑。提交信息以「聊天改进：」开头，验收写 docs/聊天改进验收.md，最后给我一段中文完成说明。
```
