# 聊天改进 任务 6：群聊不点名就由主编答

> 2026-10-23 作者让 Claude 直接做了，不用再发给 Codex，这份留着当记录。

共同约定照本目录的 `README.md`。后端为主，界面只改三处字。

## 为什么做

作者 2026-10-23 在《佔位》里和主编聊开书，聊到一半两次换成了设定师接话：一句话里有「金手指」，另一句里有「设定」（「一点一点延伸着把东西设定就补全了」），就被按关键词分给了设定师。同一件事聊到一半换人，口气和想事的角度都断了。作者定了：群聊里不点名，一律由主编答；想找设定师、写手、审稿，就打 @ 点名。

现在不点名时，有三处在挑人，都要改掉：

- `services/chat_agent.py` 的 `ROLE_WORDS`、`pick_role`：模型能调工具时走这里，`services/group_notes.py` 里普通书和拆的书的群聊都用它。
- `services/chat_context.py` 的 `obvious_question`：明显是问句、模型又不能调工具时走的捷径，也按词挑人。
- 模型不能调工具时，分流（提示词 `library_route.md`，结果 `LibraryIntent`）判成「提问闲聊」，就用它给的 `who` 定人（`group_notes.py` 的 `apply_intent`）。

## 1. 谁来答

- 群聊里作者点了名（`body.ask`）：照旧由他答、由他做。
- 没点名：一律由主编答、主编做。普通书、拆的书都一样；能调工具、不能调工具、明显问句的捷径、分流后的提问闲聊，也都一样。
- 私聊（`body.to`）照旧。
- 按话里的词挑人的代码删掉：`ROLE_WORDS`、`pick_role` 都删；`obvious_question` 只管认出是不是问句，不再挑人。
- 以前的消息里存着的 `chat_role` 照旧认：重新回答、重试，照旧由当初接话的人答。

## 2. 分流不再挑人

- `LibraryIntent`（`agents/schemas.py`）去掉 `who` 字段。
- `library_route.md` 换成本目录的 `提示词/library_route.md`，用 `git mv -f` 搬过去。这份只删了第 5 条「提问闲聊时，who 选最合适回答的人……」，后面两条的编号改成 5、6，别的一个字不动。搬完把 `backend/tests/chat_task6_prompt_hashes.json` 里 `library_route` 的指纹换成 `2389cf5669643406206df744c6b89accd11940371a9c5c1afeeaba4770cb9139`。
- 演示模型（`llm/demo.py`）分流时按词编 `who` 的那一段跟着去掉。
- `prompts/catalog.py` 里的 `"who": "和谁聊"` 是 `chat_plan`、`chat_summary` 的变量，和这里无关，不动。

## 3. 界面上的字

`frontend/src/pages/workspace/Chat.tsx`：

- 空聊天时那句「想改哪儿、想问什么直接说，编辑部自己挑人来答。想找谁，就打 @ 点他的名：」改成「想改哪儿、想问什么直接说，主编来答。想找谁，就打 @ 点他的名：」。下面四个人的列表不变。
- 两处「不点名了」按钮的提示「不点名，让编辑部自己挑人答」都改成「不点名，由主编来答」。

原型页的模拟（`chatSim.ts` 的 `pickRole`）也改成没点名就是主编，注释跟着改。

## 4. 设计说明

`docs/设计说明.md` 里三处跟着改：

- 「去掉私聊，只留一个聊天」那条：「不点名由编辑部自己挑人答」改成「不点名由主编答」。
- 「谁答谁做」那条：「不点名时编辑部按话里的内容挑人（不另调模型挑），也由他做」改成「不点名时由主编答、主编做」。理由后面补一句：按词挑人常挑错，同一件事聊到一半换人，口气和思路都断了。
- 讲代码在哪的那条里，`services/chat_agent.py` 后面括号里的「挑人、」去掉。

## 5. 测试

- 群聊不点名，话里有「金手指」「设定」「毛病」「怎么写」：模型能调工具时由主编答（`chat_role` 是 `chief`）；不能调工具时，明显问句的捷径、分流判成提问闲聊，也都是主编答。
- 点名设定师问同一句：设定师答。
- 拆的书群聊不点名：主编答；点了名照旧。
- 私聊照旧。
- 认旧行为的测试照新行为改，不要删：`test_chat_agent.py` 的 `test_pick_role_and_router_helpers`、`test_chat_stream.py` 的 `test_ask_picks_who_answers`，还有前端 `workspace-step5.browser.mjs` 里认旧字、认「没点名自己挑人」的地方。

## 6. 不做

- 别的提示词一个字不改：`chat_agent`、`chat_reply`、四份人设、手册这次都不动。
- 点名的方式（打 @、一次只点一个）不改。
- 分流的其余判断（改设定、新建设定、写大纲、写作要求、提问闲聊怎么分）不改。
