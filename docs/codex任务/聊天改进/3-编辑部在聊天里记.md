# 聊天改进 任务 3：编辑部在聊天里自己记

共同约定照本目录的 `README.md`，在任务 2 的基础上做。设计依据是 `docs/主编聊天/记忆系统.md`（第三版，下面叫「设计稿」）第 2～4 节和第 9 节；本文件和设计稿说法不一样的，照本文件。

**这次要改提示词**，改哪几处、改成什么，第 2 节写死了，照着逐字改。

## 为什么做

作者说「记住……」，或者表明了喜好、忌讳，否掉一个方向并说了理由，编辑部要自己记下来。之后点了「新对话」也记得，不用作者再说一遍。

作者的群聊现在走能调工具的那条路（chat_agent），所以给它三个工具：记（remember）、翻（read_memory）、删（forget），再把记忆目录放进聊天提示词。

## 1. 三个工具

- remember、read_memory、forget 的说明、参数和回给模型的话，逐字照设计稿 9.4。做成了的都以「做成了：」开头。
- 给谁：
  - 群聊里能调工具的那条路都给，包括「只查只答」的那种（`ask_only`），因为记忆不是改书。
  - 拆的书的群聊不给，照手册的 `allow_skills` 那样加个开关。
  - 私聊、不能调工具的群聊本来就没有工具，不管。
- 不算「动手」：不占 make_changes 的那两回，不进方案卡，不算处数。
- 编辑部正在写、在等作者拍板的时候，照样能用。
- 编号只认 `<记忆>` 目录里有的：全局加这本书、没删、没过期。别的书的、删掉的、过期的、没有的，照 9.4 回「没做成：……」。
- remember：
  - 填了全局，又填了只管下一章、这一卷、下一卷：存成这本书，回话照 9.4。
  - 带编号改一条：改之前的样子存着，好让「撤销」换回去。
  - 同一个库、同一种里，简述和已有的一条一字不差：不重记，回话照 9.4。
  - 每条存「从哪来＝聊天里记的」，记在作者那句话上。
- 回答框里正在做的那一行（`doing_of`），后面照别的工具加「……」：
  - read_memory：「在翻记忆」；
  - remember：「在记」；
  - forget：「在删一条记忆」。
- 「查了」那一行：read_memory 翻的每条写成「记忆「{简述}」」；点开看到的，是交回给模型的那一段。

## 3. 回答下面的那几行

- 照设计稿第 4 节的表，一共三种，每行都带「撤销」：
  - 「记住了：{简述}」：用任务 2 做好的那一个；
  - 「改了一条记忆：{改后的简述}」：撤销是换回改之前的样子，简述、详细内容、种类、库、管多久都换回去；撤销以后，这一行变成「换回了原来的：{原来的简述}」；
  - 「忘掉了：{简述}」：撤销是找回来，编号不变；撤销以后，这一行变成「找回来了：{简述}」。
- 放在编辑部那条回答下面，和「查了：……」一样的小字，排在「查了」那一行下面，一条一行，照发生的先后排。
- 编辑部正在写的时候记的写书时照做：照任务 2，淡字后面加「 · 正在写的从下一步起照办」。
- 后来又改过、删过的：「撤销」变灰，悬停提示照任务 2 的两种。
- 点「记住了」「改了一条记忆」那一行的字：打开记忆页，跳到那一条。「忘掉了」那一行点了不跳。
- 作者点「重新回答」：上一回记、改、删的不退，和改书一样；上一回那几行跟着旧回答一起换掉。新的回答照常记；目录里已经有的，模型会改那一条。
- 修改（退回聊天）：记忆不退，提醒里不数记忆。任务 2 已经做了，这次确认 tools 这条路也一样。

## 4. 演示模型

`llm/demo.py` 要认得新的 `<记忆>` 段，并且会调这三个工具，够浏览器测试用就行：

- 作者说「记住……」「以后都……」：调 remember；
- 作者说「这条不用记了」「记错了」：调 forget；
- 作者问「你记得我说过……吗」：调 read_memory，照翻到的回答。

## 5. 不做

- 私聊、不能调工具的群聊不能记。私聊里说「记住」，编辑部会请作者去群聊说，那句在 how_to_apply 里（9.7）。
- 看稿意见交给主编判断：任务 4。
- 拆的书不接记忆。

## 6. 测试

1. **后端**
   - 三个工具的说明、参数和设计稿 9.4 逐字一致。
   - 回给模型的话，每种情况一个用例：
     - 新记；改；
     - 全局加只管下一章；
     - 简述重复；
     - 删；
     - 编号不在目录里，分别是别的书的、删掉的、过期的、没有的；
     - read_memory 翻到有的和没有的。
   - 拆的书群聊没有这三个工具；`ask_only` 的那种有。
   - chat_agent、chat_reply 拼出来的提示词里，`<记忆>` 目录照 9.3：分组、括号、没有的组不写、一条都没有时写「还没有记忆」、过期的不列、全局在前。
   - `ACT_RULE`、make_changes 里没有写作要求了；9.7 那几句的新字。
   - 撤销三种都能撤；后来改过、删过的不能撤，接口拒绝并说清为什么。
2. **前端单元**：三种行、撤销以后的字、两种变灰。
3. **浏览器测试**（演示模型，真鼠标、真键盘）
   - 说「记住，以后每章结尾都留个钩子」：回答下面出「记住了：…」，记忆页里有；点撤销变「没记：…」。
   - 说「这条不用记了」：出「忘掉了：…」；撤销，找回来了，编号不变。
   - 改一条：出「改了一条记忆：…」；撤销，换回原来的。
   - 点「新对话」以后问「你记得我说过什么吗」：回答里用上了记忆。
   - 「只查只答」的那种问话里也能记。
   - 拆的书群聊里说「记住……」：没记，也没有那一行。
4. **旧测试**：认旧字、旧指纹的，照新的改。
5. **页面比对**：精髓 28 组、装修 16 组照跑。
