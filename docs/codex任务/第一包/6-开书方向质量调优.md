# 任务 6：开书方向的质量调优

> 先读 `docs/codex任务/第一包/README.md` 和 `docs/设计说明.md` 第 11.3、11.10 节（已更新）。任务 1-5 已完成并提交。

## 背景

作者用真实模型（gemini-3.8-flash）开了一本书，点子是「借用《我有一座恐怖屋》的设定，写一个不同剧情的小说」。两轮方向都不理想：

1. **跑题**：提示词要求「主角、金手指、开局、舞台至少两项不同」，作者点名借用的设定被硬改掉了，三个方向里有两个变成了缝尸、戏楼，失去了原作的感觉。
2. **作者看不到模型怎么理解对标作品**：模型对原作理解偏了，作者没法纠正，只能整轮重来。
3. **重出时看不到上一轮**：作者说「感觉完全不一样」，但模型不知道上一轮具体是什么，只能盲改。
4. **方向名像书名，而且起得差**：比如「诡舍迷踪」「殓尸诡录」，作者以为那是书名。
5. **金手指质量低**：为了满足「写清代价」，硬加了「午夜重演受害者死法」这类折磨式代价，还堆了好几种机制。
6. **舞台阶梯写成了一串副本地点**：比如「凶宅 → 精神病院 → 祭村」，而不是城市 → 更大的城市、大陆 → 上界这种大地图。
7. **篇幅选项太少**：最长只有「300 万字以上」，作者熟悉的千章以上长篇没有对应选项，也看不出章数是按每章多少字算的。

本任务只改「选方向」这一步和概念、设定两个提示词，不需要数据库迁移。

## 3. 流程与接口

- **上一轮的方向**：
  - 作者点「都不满意，重新出」时，流程在重新生成之前，把这一轮的 `reference` 和 `directions` 存为 `previous_directions`，连同这次的意见一起，渲染进 `{{previous}}`：

    ```
    【上一轮的方向（作者不满意）】
    你对对标作品的理解：……（有才写）
    1. 方向「诡舍迷踪」：一句话故事……；金手指：……；舞台阶梯：……；书名候选：《……》《……》
    2. ……
    作者的意见：……
    ```

  - 第一轮为空串。只保留最近一轮，作者历次的意见本来就在作者要求里。
  - `redo` 的恢复值要带上 `feedback`。接口已经拿到它，入队时一并传给流程。
- **选书名**：
  - `POST /jobs/{id}/directions` 的 `choose` 新增可选的 `title`，必须是所选方向 `titles` 里的一个，否则返回 422。
  - 选了书名时，记一条作者要求「书名用《{title}》」，来源 `answer`；作者消息为「选方向「{name}」，书名用《{title}》。」。
  - 概念生成后，程序保证 `concept.title` 等于作者选的书名；模型改了就改回来，原来的写法放进备选书名。
- **方向文字**：`format_direction_choice` 增加两行：「书名候选：《A》《B》」，以及选了书名时的「作者选定的书名：《A》」。
- **篇幅选项**：把固定的 `LENGTH_QUESTION` 改为 `length_question(chapter_words)`。一口气模式的提问也用它。
  - `chapter_words` 取本书设置里的每章字数，没有设置时用 3000。
  - 五档：
    - 「约 50 万字（短篇，约 N 章）」
    - 「约 100 万字（中篇，约 N 章）」
    - 「约 200 万字（长篇，约 N 章）」
    - 「约 300 万字（长篇，约 N 章）」
    - 「500 万字以上（超长篇，约 N 章起）」
  - N 等于字数除以每章字数，四舍五入到 10。
  - 推荐第 3 档。
  - pending 的 `length` 里加上 `chapter_words`，供界面显示。

## 4. 界面（`DirectionSelection`）

- **对标作品理解**：`reference` 不为空时，方向卡上方显示一块「主编对对标作品的理解」，正文下方加一句提示：「理解得不对？在下面「都不满意，重新出」里告诉主编，主编会按你的说法重出。」
- **方向卡**：
  - 卡头改成小号的「方向一 · {name}」，不再用大号宋体，免得被看成书名。
  - 卡头下面是「书名候选」：两个可以点选的书名标签，单选，再点一次取消；旁边加一句辅助说明「不选也行，定调时主编会再起」。
  - 「选这个」提交时带上选中的书名。
- **篇幅提示**：篇幅选项下方加一行辅助说明：「按每章约 {chapter_words} 字估算章数。想要章数更多、每章更短，先到「本书设置」改每章字数，再点「都不满意，重新出」。」
- **旧数据兼容**：pending 里没有 `reference`、`titles`、`chapter_words` 的，照原样显示。

## 5. 演示模式

- `BookDirections`：点子里出现「借用」「像」「对标」或书名号时，给出 `reference`；每个方向带 2 个书名候选。
- 重出时：提示词里有【上一轮的方向】的，演示产出要和上一轮明显不同，供测试使用。

## 6. 测试

- schema 描述与本任务代码块逐字一致。
- `{{previous}}`：第一轮为空；重出时包含上一轮的方向和作者的意见；只保留最近一轮。
- 选书名：
  - 书名不在候选里时返回 422；
  - 选了书名时作者要求和作者消息正确；
  - 概念生成后书名被程序保证为选定的书名。
- `length_question`：每章 3000 字和 2000 字时，五档的文字和章数正确；推荐第 3 档。
- 前端：对标作品块、方向卡标签和书名单选、篇幅提示的 node 测试或浏览器回归；旧 pending 兼容。
