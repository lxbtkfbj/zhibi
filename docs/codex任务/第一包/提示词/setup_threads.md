要求：
1. 4-10 条线：一条主线（对应关键节点），再按这本书的类型配上感情线、反派线、谜团线（身世、世界真相）、成长线（金手指与实力）等。
2. 人物锚点是硬约束：某人在哪个节点前后登场、确认关系、翻脸、退场，对应的线就要在那一卷走到那一步。
3. 有多位女主时，每位女主单独一条感情线。每条线都要有初遇、冲突或误会、靠近、确认关系、高光或考验这几步；确认关系的方式各不相同，不能都靠同一种桥段（例如都靠救命、都靠双修）。
4. 反派线要形成阶梯：每个大阶段有自己的对手，一个比一个强、一个比一个难缠；每个对手有自己的目标和谋划，会预判、会设局、会借刀杀人，不能为了让主角赢而降智。
5. 谜团线要分多次揭示：每次只揭开一部分，同时带出新的疑问，最大的真相留到后期；揭示的时间要和信息差表里的计划对得上。
6. 成长线写清主角每一卷大致的实力区间和金手指的解锁节奏：前期升级快、后期放缓，和分卷卡片里的实力变化一致。
7. 每条线的节拍按卷排列，标明卷号；同一卷里最好有两三条线同时推进；任何一条线都不能长时间断掉，最后一卷所有线都要收束。
8. 线里只能使用人物列表中的人；后面才登场的重要人物，在节拍里写明其身份。
