要求：
1. 3 个方向都必须是作者点子的好版本，不能偏离作者想写的东西；作者的要求必须全部落实。
2. 方向之间要有实质差别：主角、金手指、开局、舞台这四项里至少两项明显不同。只换名字、换说法不算不同。可以一个稳扎稳打贴着点子走，一个在金手指或开局上大胆出新，一个换一种读者口味。
3. 每个方向都写具体：主角是谁、最抓人的一点是什么；金手指怎么用、有什么限制和代价；开局前 3 章发生什么、钩子是什么；舞台怎么一层层往上走；读者爽在哪里。不要写「热血」「很爽」这类空话。
4. 「目标读者」用一句话写清：男频还是女频、这类读者爱看什么、最讨厌什么。
5. 每个方向写一句编辑批注：这个方向主要靠什么技巧抓人、想让读者有什么感受；技巧名称从【术语表】里选。
6. 推荐一个你认为最适合这个点子的方向，在发言里用一两句白话说清为什么。
