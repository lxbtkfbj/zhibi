要求：
1. 先想清楚结局，再倒推中间的节点：每个节点都要让主角离结局更近，或者付出代价、被迫改变。
2. 节点总数 8-14 个（含开篇和结局），按时间顺序排列；第一个是开篇，最后一个是结局。中间节点沿着概念里的舞台阶梯分布到各卷，每卷至少一个。换地图、卷末大场面、身份揭晓、重要的人离开或回归，都是好节点。
3. 每个节点写清三件事：
   - 发生什么：这件大事本身，具体到人和场面。
   - 之前得先有：要让这件事发生、并且让读者觉得合理，前面必须已经具备的实力、关系、仇怨、秘密或局势。这是后面分卷要铺垫的东西，写得越具体，后面越好写。
   - 之后变成：主角和局势发生了哪些回不去的变化（实力、地图、关系、敌人、目标）。
4. 开篇节点必须在前 3 章抛出核心钩子；结局要回应开篇和核心矛盾。
5. 相邻两个节点之间要有路可走：后一个节点的「之前得先有」，要能从前一个节点的「之后变成」出发，经过一两卷剧情达到；跨度太大，就在中间补一个节点。
6. 节点的类型要有变化：不要全是「打败更强的敌人」，穿插揭秘、失去、选择、重逢、背叛、身份翻转。
7. 人物还没定，节点里需要的人用身份来写（如「宿敌」「第一位女主」「师尊」）；作者点子里已经有名字的，直接用名字。
8. 主角的成长弧线要和核心矛盾绑在一起：主角最后能赢，是因为他变了。
9. 每个节点写一句编辑批注：这个节点用了什么技巧、想让读者有什么感受；技巧名称从【术语表】里选。
10. 列出你替作者做的、作者可能想换的关键决定，最多 3 个（例如结局走向、中期最大的转折、开篇切入点），每个给出 1-3 个可换的选项和一句理由。
11. 修改已有的节点时：标着［铁钉］的节点是作者亲自确认的，原样保留——ref 填它现在的序号，内容一字不改；修改要求里写明「作者要求改动铁钉节点 N」的，只按作者的要求改那一个。其余只改［暂定］的节点和修改要求点名的地方。改写已有节点时 ref 填它现在的序号，新增的节点 ref 填 0。
