# 任务 5：写作阶段界面（前端为主）

> 先读 `docs/codex任务/第一包/README.md`、`docs/设计说明.md` 第 9 节和第 11.10、11.11 节，并确认任务 3、4 已完成并提交。视觉规范同任务 3。

## 目标

开写之后，作者一眼能看到：

- 在全书的哪个位置、离下一个大节点还有多远；
- 每一卷、每个单元的情绪起伏，以及期待和揭晓的安排；
- 编辑部对暂定节点的调整提议，能随卷纲一起批准。

## 1. 写作位置（`lib/storyMap.ts` 新增纯函数，要有 node 测试）

`writingPosition(nodes, volumes, chapters)` 返回：

```ts
{
  volume: number | null        // 当前卷：正在写的章所在的卷；没有正在写的，取最后一章定稿所在的卷；那一卷已写完，取下一卷
  doneInVolume: number         // 当前卷已定稿章数
  volumeChapters: number       // 当前卷计划章数（有单元时取单元章数之和）
  nextNode: StoryNode | null   // 下一个要到的节点：当前卷的目标节点；当前卷已写完且本卷就是写到这个节点的卷，取下一卷的目标节点
  chaptersToNode: number | null // 从当前卷开始，到最后一个以 nextNode 为目标的卷为止，各卷计划章数之和减去当前卷已定稿章数
  passed: string[]             // 已经走过的节点 id：开篇（第 1 章定稿后），以及「以它为目标、reaches_node 为真、且已写完」的卷对应的节点
  ratio: number                // 0-1：全书已定稿章数 / 全书计划章数，画进度用
}
```

还没开写（没有定稿章节）时，返回 `volume = null`，界面不显示这条地图。

## 2. 全书地图条（新组件 `StoryMapStrip`）

- **放在哪里**：概览页原「主线骨架」区块的位置（开写后）；拼图板页头下方（开写后）。
- **画法**：一条横线，上面是节点圆点。
  - 铁钉为实心，暂定为虚线圈；
  - 走过的节点内部打勾；
  - 已写的部分用朱砂色描出，到「写到这里」为止。「写到这里」标记的位置，按全书已定稿章数在相邻两个节点之间插值。
  - 节点名称写在圆点下方，最多显示 6 个字，悬停或聚焦时显示全名，点击跳到拼图板上对应的节点。
- **文字行**：「第 3 卷 42/60 章 · 离「飞升神界」还有 18 章」。没有下一个节点时写「正在写最后一段，离结局还有 N 章」；全书完结时写「全书完结」。
- **节点太多时**：节点超过 8 个，或者稿件栏窄于 560px，只显示开篇、结局、当前位置前后各 2 个节点，中间省略处用「…」。不做横向滚动。
- **无障碍**：整条地图有文字摘要（`aria-label`，内容就是文字行）；遵守 reduced-motion。

## 3. 拼图板（开写之后）

- 页头下方显示 `StoryMapStrip`。
- 走过的节点卡片标记打勾，加「已写到」字样；当前所在的分段带高亮，并显示「正在写：第 3 卷 42/60 章」。
- 「换候选」「补空位」在开写后不显示；插入新节点时弹出名称输入框，新建为铁钉（任务 3 已实现，这里确认无误）。
- 暂定节点被卷纲调整过时（`updated_by_volume` 不为空，任务 4 已加这个字段），卡片上显示一行辅助说明「第 N 卷拆卷纲时调整过」。

## 4. 卷页

- **卷卡片**：
  - 显示「走向：节点 5「飞升神界」」，节点是铁钉 / 暂定用小标记区分；`reaches_node` 为真时加「本卷发生」；
  - 显示编辑批注和技巧标签；
  - 点击节点名跳到拼图板。
- **单元卡**：
  - **情绪小曲线**：用本单元各章章纲的 `emotion` 画一条小折线，高 32px，宽度跟随卡片，-2 到 2 映射为下到上，0 处画一条淡线；每章一个点，点上的提示文字为「第 12 章 · -1 偏压 · 虐」。没有章纲（还没出）或旧章纲没有情绪数据时不画，写「出章纲后显示情绪曲线」。
  - **主情绪**：曲线下方按章依次显示主情绪的小字（爽 / 燃 / 虐 ……），连续 4 个相同的用警示色。
  - **期待与伏笔动作**：小标签，期待用「立下 E3」「提醒 E3」「兑现 E3」，伏笔用「埋下 F5」「回收 F5」，悬停显示内容。
  - **揭晓**：小标签「揭晓 S2 → 柳如烟」，悬停显示怎么揭。
  - **编辑批注、技巧标签**。
  - **节奏问题**：`plan_issues` 不为空时，卡片顶部显示提示「章纲还有 N 处节奏问题」，点开列出来。
- **卷纲拍板**：pending 里有 `node_update` 时，拍板条下方显示「这一卷建议调整暂定节点「X」」，以及前后对比（名称、发生什么、之前得先有、之后变成，两列或上下对照，改动处用下划线标出），并附一句理由。批准卷纲就会应用，按钮文字不变，提示文字写明「批准卷纲会同时应用这个调整」。有 `node_conflict` 时显示警示框「节点冲突：……」。

## 5. 章节页

- 章纲抽屉里显示「情绪：+2 爆发爽快（爽）」和揭晓。
- 伏笔动作里的期待用 立下 / 提醒 / 兑现 的说法和 E 编号。

## 6. 顶栏进度文字

`progressText` 在开写后、能算出 `writingPosition` 时，写成「第 3 卷 · 已定稿 120 章 · 离「飞升神界」还有 18 章」；后面接工作状态的规则不变。

## 7. 测试

- **node 测试**：
  - `writingPosition`：未开写、写到一卷中间、正好写完本卷就是节点所在的卷、两个节点之间跨多卷、全书完结、旧数据卷没有目标节点；
  - 情绪曲线的坐标映射函数；
  - 地图节点省略规则；
  - `progressText` 的新文案。
- **类型检查、lint、build** 通过。

## 8. 验收（演示模式，浏览器）
