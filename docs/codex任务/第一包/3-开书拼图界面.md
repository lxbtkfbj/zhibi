# 任务 3：开书拼图界面（前端为主）

> 先读 `docs/codex任务/第一包/README.md`、`docs/设计说明.md` 第 9 节和第 11.10 节，并确认任务 1、2 已完成并提交。界面沿用现有的宣纸视觉、组件和动效规范（第 9.4、10.1 节）：辅助字最小 12px，正文类最小 14px，遵守 reduced-motion，暗色模式下颜色正确。

## 目标

作者在网页上用「逐块确认」完整开一本书：

- 能看清拼到第几块；
- 能在拼图板上钉节点、改节点、要候选、补空位；
- 能逐块确认、换掉编辑部替自己做的决定、重新打开已确认的块。

本任务完成时把默认开书方式改为逐块确认。

## 1. 默认值与入口

- **默认值**：后端 `BookSettings.setup_mode` 默认值改为 `"puzzle"`；新书默认同步改。已有书不受影响。
- **首页**：创建区新增「开书方式」分段选项「逐块确认（推荐）｜一口气出方案」，默认值取新书默认。
  - 只有选「一口气出方案」时才显示现有的「先问我几个问题」开关。
  - 选择不写入本机存储，以新书默认为准。
  - 创建时把 `mode` 传给 `POST /books`。
- **设置窗口「新书默认」**：新增一行「开书方式」，分段选项「逐块确认｜一口气出方案」，说明文字「逐块确认：每做完一块停下来等你确认；一口气：做完整套方案再一起拍板」。

## 2. 类型与数据

- **`api/types.ts`**：
  - `Pending` 增加 `setup_directions`（`directions`、`recommended`、`length`）和 `setup_piece`（`piece`、`round`、`warnings`、`decisions`、`suggestions`、`unlock_requests`、`candidates`）。
  - 新增 `BookDirection`、`AuthorChoice`、`SetupProgress`、`PieceKey` 等类型。
- **`api/hooks.ts`**：
  - `useJobActions` 增加 `chooseDirection`、`redoDirections`、`pieceAction`（`confirm`、`delegate`、`revise`、`candidates`、`fill`、`reopen`、`unlock`）。
  - 新增 `useGlossary`（缓存不过期）和锚点的增删改。
- **纯函数**（新建 `lib/storyMap.ts`，都要有 node 测试）：
  - `PIECES`：五块的 key、名称、对应页面路径——concept → `/concept`，nodes → `/spine`，cast → `/characters`，fill → `/spine`，first_volume → `/volume/1`。
  - `pieceStatuses(progress)`：返回五块各自的状态和当前块。
  - `nodeCounts(nodes)`：返回 `{total, pinned, pencil, empty}`。
  - `segments(nodes, volumes)`：把卷按 `target_node_id` 归到相邻两个节点之间，返回 `[{from, to, volumes, chapters}]`。没有目标节点的卷归到最后一段并标出来。

## 3. 工作台

- **拼图进度条**（新组件 `PuzzleTracker`，放在稿件栏顶部、拍板条之上）：
  - 什么时候显示：书处于 `setting_up`，或者当前有开书任务。
  - 内容：一行五块，状态有已确认（勾，成功色）、正在做（主编色小圆点，有轻微呼吸动效）、等你确认（主编色描边高亮）、未开始（淡色）、一口气模式下已做完（淡色勾）。节点块显示「节点 已钉/总数」。
  - 点击：等同手动导航（停止跟随），进入那一块的页面。
  - 小于 768px 宽时：缩成一行「② 节点 6/9 · 等你确认」，点击展开五块。
- **左栏书稿目录**：
  - 开书期间，最上面加一组「开书拼图」，列出五块和状态图标（同进度条），点击进入对应页面。
  - 开书完成后这一组不显示。
  - 「主线骨架」改名「全书地图」，图标保持。
- **拍板条**：
  - 等待 `setup_piece` 时：
    - 文字「待你确认：{块名}」，后面加一个括号，写最重要的一条提醒，例如「（还有 1 个空位）」；
    - 按钮「确认这一块」（主按钮）和「交给编辑部定」；
    - 有提醒、建议或解锁请求时，在条下方显示可折叠的列表：
      - 提醒：只读。
      - 审稿建议：每条带「解锁并修改」。按 `target` 映射到所属的块，调 `pieceAction('unlock', {piece, feedback: 问题 + 建议})`。
      - 解锁请求：每条带「解锁并修改」，`feedback` 用请求里的理由。
  - 等待 `setup_directions` 时：文字「待你选择：开书方向」，附「去选择」链接，指向概览页。
  - 动作发出期间按钮显示加载状态，防止重复点击；失败时提示错误。
- **跟随与进度文字**（`lib/workspace.ts`）：
  - `pendingTarget`：`setup_directions` → 概览页（「开书方向」）；`setup_piece` → 该块的页面（「第 N 块：块名」）。
  - `artifactTarget`：`directions` → 概览页；`spine` → `/spine`（「关键节点」）；`outline` → `/spine`（「填中间」）。其余不变。
  - `progressText`：逐块模式下
    - 工作中：「开书 · 第 2 块「关键节点」· {最新状态}」；
    - 等确认：「等你确认：关键节点」；
    - 等选方向：「等你选择：开书方向」。

## 4. 选方向（概览页）

等待 `setup_directions` 时，概览页的「下一步」区块显示方向选择，替代原来的提问表单的位置。

- **篇幅**：顶部单选，选项和推荐项来自 `pending.length`，默认选推荐项。
- **方向卡**：三张竖排，每张显示名称（推荐的加「主编推荐」角标）、一句话故事，以及主角、金手指、开局、卖点、舞台阶梯、基调、目标读者、与其他方向的区别（带标签的短行），底部是编辑批注和技巧标签（见第 8 节）。每张卡有「选这个」按钮。
- **混搭**：方向卡下方一个输入框「想混搭就写在这里（比如：用方向一，但金手指换成方向二的）」，内容随「选这个」一起提交。
- **重新出**：「都不满意，重新出」展开一个输入框，写上不满意的地方后提交 `redo`；没写内容时显示行内错误「写一下哪里不满意」。
- **提交后**：显示「主编正在按你的选择定调…」，进度条随之更新。

## 5. 替你做的决定、重新打开、对话联动

- **替你做的决定**（新组件 `PieceDecisions`）：
  - 什么时候显示：当前等待的块就是这个页面所属的块（概念页、拼图板、人物页、第一卷卷页）。
  - 显示：页面顶部列出 `pending.decisions`，每个决定一行：主题、当前选择（默认选中）、可换选项（单选）、为什么（辅助说明）。
  - 改了任何一个选择时，出现「按我选的改」，提交 `revise`，带 `flips`。
- **重新打开**：开书期间，已确认块的页面顶部显示「重新打开这一块」。
  - 点击后弹出确认框：「重新打开后，后面已经确认的「……」也会按新的内容重新检查一遍。」确认后调用 `reopen`。
  - 有任务在跑时不显示。
- **对话联动**：
  - 卡片上的「改」：切到群聊，聚焦输入框，预填「关于节点 3「飞升神界」：」，并在会话层记下 `node_id`。
  - 发送时，如果当前等待 `setup_piece`，就作为 `revise` 提交（带 `node_id`），预填前缀会一起作为 feedback 发出。如果没在等待（比如开写之后），就按普通插话发给主编。
  - 用户清空了输入框里的前缀时，丢掉 `node_id`。
  - 等待 `setup_piece` 时，输入框占位文字为「说说这一块想怎么改…」；等待 `setup_directions` 时，发送等同「重新出」并附上内容。

## 6. 拼图板（`/spine`，替换现在的 SpinePage）

- **页头**：eyebrow「全书地图」；开书期间节点块未确认时，标题为「关键节点」。下面一行统计「9 个节点 · 5 铁钉 · 3 暂定 · 1 留空」。
- **核心字段**：核心矛盾、主题、主角成长弧保留，仍然可以就地编辑。
- **时间轴**：竖向；节点卡的标记按状态区分：
  - 铁钉：实心朱砂圆，带图钉图标；
  - 暂定：虚线圆；
  - 留空：点线圆和点线边框的空卡。
- **节点卡内容**：
  - 名称（宋体）、状态文字、约第几卷；
  - 发生什么；
  - 之前得先有、之后变成（各一行，带小标签）；
  - 人物锚点小标签（「林岚 · 登场」，悬停或聚焦时显示说明）；
  - 编辑批注和技巧标签。
  - 文字字段都用现有的 `EditableText` 就地编辑。
- **卡片按钮**（图标按钮带 `aria-label` 和 title）：
  - 钉死 / 改暂定：PATCH status。
  - 改：对话联动，见第 5 节。
  - 删除：确认框，开篇、结局不显示这个按钮。
  - 在下面插入：开书期间新建一个留空节点（`status=empty`）；开写之后弹出名称输入框，新建铁钉节点。
  - 上移、下移：调用重排接口，开篇、结局不能移动。
  - 换候选：只在开书期间、且正在等待节点块确认时显示。
- **留空卡**：两个按钮「给我 3 个候选」和「补上这个空位」，外加一个输入框「我自己写一句」。写了一句并提交时，发 `fill` 并把这句话作为 `feedback`（见任务 2 第 2.7 节）。
- **候选**：`pending.candidates.node_id` 等于某个节点时，在该节点下方显示三张候选卡（内容同节点卡，只读）：
  - 「用这个」：PATCH 节点的 title、event、prerequisite、consequence、volume；原来是留空的改为暂定，其余状态不变；
  - 「都不要」：只在本地收起。
- **分段带**：有分卷后，在相邻两个节点之间显示「第 3-4 卷 · 约 110 章」，点击展开这几卷的迷你卡片（卷名、章数、卷末目标），可以点进卷页。
- **长线伏笔与期待**：有分卷后，时间轴下方显示「长线伏笔与期待」折叠区，列出 F、E 编号、内容和埋收（立兑）的卷，期待在前。
- **锁定**：有任务在跑时，整页只读，顶部显示现有的 `Locked` 提示；等待作者时可以编辑。
- **开书预览**：节点块正在生成、数据库里还没有新数据时，沿用现有的只读预览机制。
- **会议记录卡片**：新形状的 `spine`、`lore`、`outline`、`directions` 产出卡片排版整齐，点开跳到对应页面。

## 7. 人物上轴与设定库页面

- **人物页**：每个人物卡显示他的锚点（「节点 3「回幻妖界」· 登场——……」），可以增删改：节点用下拉选，类型用分段选项，说明用就地编辑。
- **信息差页**（新页面 `/books/:bookId/secrets`，左栏设定库里加入口「信息差」，显示条数）：
  - 每个秘密一张卡：编号、短名、状态（隐藏 / 公开）、读者知不知道（知道 / 不知道 / 部分 / 未标注）、真相、知道的人（小标签「林岚 · 开书时」「赵青 · 第 35 章」，悬停显示怎么知道的）、计划怎么揭、揭开节点。
  - 可以新增、编辑、删除；知道的人可以加减。
- **伏笔页改为「伏笔与期待」**：
  - 顶部筛选「全部｜伏笔｜期待」；
  - 编号用接口返回的 `code`；
  - 期待的状态词为 未立 / 已立 / 已兑现 / 放弃，动作词为 立下 / 提醒 / 兑现；
  - 新增条目时可以选类型。
- **人物上轴块等确认时的提示**：人物页顶部提示「这一块还包括世界观、人物关系和信息差」，附三个链接。

## 8. 术语与提示词页

- **技巧标签**（新组件 `TechniqueChip`）：
  - 小号描边标签；
  - 点击或回车打开说明浮层，内容是术语和白话解释，数据来自 `useGlossary`；
  - Escape 关闭，焦点回到标签；
  - 术语表里没有的名称显示为纯文字。
- **编辑批注**：显示在卡片底部，用辅助说明字号，前面加小号「批注」字样。
- **提示词页**：模板 `default_changed` 为真时，在名称旁显示「默认版本已更新」，详情区说明新增了哪些变量，提供现有的「恢复默认」。

## 10. 验收（演示模式，浏览器）

按顺序跑一遍，每步截图，结果写进 `docs/第一包验收.md` 的「任务 3」小节：

1. 首页默认是「逐块确认」；切到「一口气」时才出现「先问我几个问题」。
2. 新建一本书：概览页出现三张方向卡和篇幅选项；进度条显示「定调」正在做或等你选。
3. 选一个方向，填写混搭：概念页出现「替你做的决定」和待确认条。换掉一个决定并点「按我选的改」，概念随之更新。
4. 确认定调 → 拼图板：统计行、三种节点样式、批注和技巧标签（点开能看到解释）。
5. 在拼图板上依次操作：钉一个节点；改一段文字；在某个节点下面插入一个留空节点，用「我自己写一句」补成铁钉节点；对一个暂定节点要候选，点「用这个」；删除一个节点；上移一个节点。
6. 在某张卡片上点「改」：群聊输入框出现预填前缀，发出后这一块按意见修改，铁钉节点不变。
7. 留一个空位直接点「确认这一块」：空位被补上，进入人物上轴；人物页能看到锚点；信息差页能看到秘密和知道的人。
8. 填中间：拼图板出现分段带和「长线伏笔与期待」；「伏笔与期待」页可以按类型筛选。
9. 第一卷：卷页出现待确认条；有审稿建议时，点其中一条的「解锁并修改」，对应的块回到修改中，之后逐块再确认。
10. 确认第一卷：盖章动效出现，进度条消失，左栏「开书拼图」组收起，「全书地图」入口正常。
11. 新开一本书，在填中间等确认时，重新打开「关键节点」：节点块回到等确认；确认后后面的块重新生成。
12. 窄屏（小于 1024px）：讨论 / 稿件切换正常；进度条缩成一行。暗色模式下拼图板截图一张。
13. 一口气模式开一本书：流程同改版前；拍板前可以在拼图板上钉节点，提意见后铁钉节点不变。
